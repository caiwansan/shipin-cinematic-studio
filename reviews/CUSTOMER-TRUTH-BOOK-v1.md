# Customer Truth Book v1

> **GEO 客户真相手册**  
> **版本**: v1.0 — FCV-1 输出的客户行为证据  
> **格式**: 不按页面/功能整理，按 Truth 编号

---

## 格式模板

每条 Truth 包含：

```
## Truth #XXX

### 观察
[用户行为描述]

### 证据
[录屏时间戳 / 原话 / Dashboard 指标]

### Root Cause
[推断的根因]

### Severity
[S0 / S1 / S2 / S3]

### Fix
[修复方案]

### Validation
[如何验证修复有效]

### 来源
[FCV-1 / FCV-2 / ... | 用户角色 | 用户 ID]
```
