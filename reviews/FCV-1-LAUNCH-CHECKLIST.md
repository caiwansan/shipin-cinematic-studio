# FCV-1 Launch Checklist

> **版本**: v1.0 | **用途**: FCV-1 开始前的最后一道闸门  
> **原则**: 所有项必须为 ✅ 才开始招募

---

## 产品环境

- [ ] 使用生产候选版本（Release Candidate），不是开发版本
- [ ] 无 Mock、Placeholder、Coming Soon
- [ ] 测试账号已准备
- [ ] 测试品牌/示例数据可正常使用（如适用）
- [ ] 日志级别调整为适合测试，不影响体验

## 数据采集

- [ ] FCV Dashboard 已建立
- [ ] VOICE-OF-CUSTOMER 已初始化
- [ ] Observation 模板已准备
- [ ] 录屏工具测试完成
- [ ] 时间统计方式一致

## 人员

- [ ] 主持人完成 Script 演练
- [ ] 观察员理解 Severity Framework
- [ ] 全员理解 Don't Build List
- [ ] Customer Truth Review 时间已预留

## 招募

- [ ] Screener 已上线
- [ ] Invitation 已审核
- [ ] Consent 已准备
- [ ] 第一批目标名单确认
- [ ] 样本角色分布符合计划

## 成功标准

- [ ] 退出条件明确
- [ ] Customer Truth Review 触发条件明确
- [ ] 修复 Sprint 流程明确

---

## Reality Gate（最终闸门）

> 以下全部满足才发出第一封邀请。

- [ ] Production/Staging 环境稳定（不是开发环境）
- [ ] 所有测试账号和数据准备完成
- [ ] 全流程录屏正常
- [ ] 主持人完整演练一次 Script（不能临场发挥）
- [ ] 观察员知道如何记录行为，而不是记录意见
- [ ] 每位参与者已经通过 Screener
- [ ] 每位参与者已经签署 Consent
- [ ] 每场测试结束后预留至少 30 分钟整理 VOC，避免堆积
- [ ] **团队承诺：FCV 期间原则上不发布新功能，只修复影响测试的严重问题**
