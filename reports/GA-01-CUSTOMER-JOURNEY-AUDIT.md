# GA-01 Customer Journey Audit — Enterprise Digital Department

**Phase**: Productization — Customer Journey Audit
**Date**: 2026-07-17
**Author**: OpenClaw (AI CTO Office)

---

## 目标

验证真实用户路径：用户能否理解、购买、创建、启动自己的 AI 数字部门。

---

## 用户旅程地图

```
Step 1: 认知      → 了解企业数字部门是什么
Step 2: 兴趣      → 查看 AI 员工能力和案例
Step 3: 考虑      → 对比套餐，评估是否适合
Step 4: 购买      → 选择套餐，完成支付
Step 5: 创建企业   → 填写企业资料
Step 6: 创建AI员工 → 选择岗位，生成身份
Step 7: 配置模型   → 输入自己的 LLM API Key
Step 8: 授权渠道   → 连接抖音/小红书/企微等
Step 9: 启动员工   → AI 员工开始工作
Step 10: 首次价值  → 看到第一个业务结果
```

## 3. 旅程断点分析

### 断点 1: 介绍页 → 购买

**现状**: 介绍页 CTA 跳转到 `/enterprise` (Workspace)
**问题**: 未购买用户进入 Workspace 会看到空页面
**修复**: 未购买用户应看到购买引导页

### 断点 2: 购买 → 创建企业

**现状**: 支付成功后无自动跳转
**修复**: 支付成功 → 自动跳转 Onboarding Wizard

### 断点 3: 创建员工 → 首次任务

**现状**: 进入 Workspace 后无首次任务引导
**修复**: 新增 "布置第一个任务" 引导
