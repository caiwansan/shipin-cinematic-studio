# BETA-06.1.3 — Enterprise Identity Boundary Fix 报告

## 问题诊断

**现象**：企业数字部门首页显示 `qq_6F736FAC37ED3A3AF774AE0924374F4D 的企业`（User.username + ' 的企业'）作为企业名称。

**根因**：
- `identity-bootstrap.service.ts` 的 `ensureOrganizationForUser()` 在没有检测到现有组织时，自动创建 `GovOrganization`，名称使用 `${userName} 的企业`
- 这导致 User Identity 和 Organization Identity 混用
- 违反了企业 SaaS 的基本信任：用户买的是"企业数字部门"，不是"用户名数字部门"

## 修复内容

### 1. Backend: Identity Bootstrap Service

**文件**: `backend/src/services/enterprise/organization/identity-bootstrap.service.ts`

变更：
- `ensureOrganizationForUser()` 不再自动创建组织
- 如果用户没有 Organization，返回空 `organizationName`（前端据此判断"未初始化"）
- 新增 `isAutoGeneratedName()` 函数，检测数据库中已有的自动生成名称（兼容存量数据）
- 新增 `createOrganization()` 函数，供前端"创建企业"引导流程调用

```typescript
// 修复前
const organizationName = userName ? `${userName} 的企业` : ...
// 创建新 org 并返回

// 修复后
// 不再自动创建 → 返回空 organizationName
// 检测存量自动生成的名称 → 返回空（触发前端引导）
```

### 2. Backend: Create Organization API

**文件**: `backend/src/routes/enterprise-foundation.ts`

新增：
- `POST /api/identity/organization` — 创建真正的企业信息
- 接受字段：`name`（必填）、`industry`、`size`、`description`、`logo`
- 验证：`name` 至少 2 字符
- 更新存量 org 或创建新 org，metadata 中存储 `initialized: true` + `initializedAt`

### 3. Frontend: Enterprise Layout

**文件**: `frontend/layouts/enterprise.vue`

变更：
- `organizationName` 不再 fallback 到 '我的企业'
- 新增 `hasOrganization` computed 属性

### 4. Frontend: EnterpriseIdentityHeader

**文件**: `frontend/components/enterprise/workspace/EnterpriseIdentityHeader.vue`

变更：
- 有企业名称：正常显示企业名 + 套餐 + 指标
- 无企业名称：显示 "我的企业"（灰色斜体）+ "尚未填写" badge + "请填写企业名称以开始使用" 提示
- 新增 "➕ 创建企业" 按钮（无企业时优先显示）

### 5. Frontend: CreateOrganizationModal

**文件**: `frontend/components/enterprise/workspace/CreateOrganizationModal.vue`（新增）

- 弹窗表单：企业名称（必填）、所属行业（下拉）、企业规模（下拉）、企业简介（可选）
- 调用 `POST /api/identity/organization` 创建企业
- 创建成功后刷新页面，加载企业数据

### 6. Frontend: EnterpriseWorkspace

**文件**: `frontend/components/enterprise/workspace/EnterpriseWorkspace.vue`

变更：
- 引入 `CreateOrganizationModal`
- 监听 `@create-organization` 事件 → 显示创建弹窗
- 监听 `@created` 事件 → 更新 authStore + 刷新页面

## 数据模型分层（修复后）

```
User Account
├── id, username, email, avatar
└── 用于：登录身份、个人设置

Organization (GovOrganization)
├── id, name, tenantId
├── metadata: { industry, description, size, logo, initialized, initializedAt }
└── 用于：企业数字部门首页、AI员工归属、订阅

Enterprise Workspace
├── AI员工、知识库、渠道、模型
└── 归属到 Organization
```

**严格禁止**: `Organization.name = User.username + ' 的企业'`

## 存量数据兼容

已有的 `GovOrganization` 记录（如 `qq_xxx 的企业`）不会被删除。
`isAutoGeneratedName()` 会检测这些记录并返回空 `organizationName`，
引导用户填写真实企业信息（更新而非新建）。
