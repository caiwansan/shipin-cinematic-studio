# HOME-NAVIGATION-V2.1 — 昆仑镜首页导航重构报告

## 任务概要

按照昆仑镜真实产品矩阵重构首页导航，从"全部横排直列"改为 **Logo + 商城 + 社区 + 更多项目 Mega Menu** 架构。

## 变更内容

### 1. 顶部导航栏 (`KunlunNav.vue`)

**变更前：**
```
Logo | 短剧工作台 | 小说工作台 | 商城 | 法律 | PPT | GEO | 电商 | 数字部门 | 社区 | 登录/注册
```
→ 全部横排，层级扁平

**变更后：**
```
Logo | 商城 | 社区 | 更多项目 ▼ | 登录/注册
```
→ 精简顶部，项目收纳进 Mega Menu

### 2. 更多项目 Mega Menu

点击「更多项目」展开三排分类：

| 内容创作 | 商业生产 | 专业办公 |
|---------|---------|---------|
| 🎬 短剧工作台 | 🏢 数字部门 | ⚖️ 法律工作台 |
| 🎵 音乐创作 (即将上线) | 🌐 GEO优化 | 📊 PPT制作 |
| 📖 小说创作 | 🖼️ 电商图片 | |
| | 📢 广告制作 (即将上线) | |

### 3. 导航配置化 (`config/navigation.ts`)

所有「更多项目」入口集中在一个配置文件：

```typescript
export const navCategories: NavCategory[] = [
  { title: '内容创作', items: [...] },
  { title: '商业生产', items: [...] },
  { title: '专业办公', items: [...] },
]

export const primaryNav: NavItem[] = [
  { label: '商城', icon: '🛍️', to: '/mall' },
  { label: '社区', icon: '🌐', to: '/community' },
]
```

**未来新增项目：只改 `config/navigation.ts`，不改导航组件。**

### 4. 交互行为

| 行为 | 实现 |
|------|------|
| 默认收起 | ✅ Mega Menu 默认隐藏 |
| 点击展开 | ✅ 点击「更多项目」按钮展开 |
| 点击外部关闭 | ✅ document 点击事件监听，点击菜单外部自动收起 |
| 项目点击关闭 | ✅ 选择项目后自动收起 Mega Menu |
| 移动端适配 | ✅ 汉堡菜单 + 折叠面板 |

### 5. 即将上线处理

- 音乐创作、广告制作：标记 `disabled: true` + `badge: '即将上线'`
- 点击无跳转，视觉上灰显处理
- 未来只需将 `disabled` 改为 `false` 即可激活
