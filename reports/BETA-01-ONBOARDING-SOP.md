# Beta Customer Onboarding SOP v1.0

## 目标

**10 家企业在 30 天内完成部署并产生首次价值。**

---

## Phase 0：客户筛选

### 筛选标准（必须满足 3/4）

| 条件 | 说明 |
|------|------|
| ✅ 有明确业务流程 | 不是"试试看看"，有具体场景 |
| ✅ 有内容/销售/客服需求 | 适配首批 3 个 AI 员工 |
| ✅ 有业务负责人参与 | 不是仅 IT 或仅老板 |
| ✅ 能投入 5 分钟/天 | 每周至少检查 1 次 AI 员工报告 |

### 优先行业

```
P0: 电商企业、MCN、教培机构、SaaS公司
P1: 品牌营销公司、外贸企业、本地服务
```

---

## Phase 1：企业初始化（5 分钟）

### 标准流程

```text
1. 注册昆仑镜（已注册跳过）
2. 进入 enterprise 数字部门
3. 点击「创建企业」
4. 填写企业资料（行业、主营业务、目标客户）
5. 点击「选择套餐」→ 月度/年度
6. 支付
7. Subscription Active → 解锁 3/10/∞ AI 员工额度
```

### 验收点

- ✅ Subscription status = active
- ✅ Plan Snapshot 已写入
- ✅ payment_success 事件已记录（TTFV 起点）

---

## Phase 2：AI 员工激活（3 分钟）

### 推荐岗位

| 岗位 | 最短价值链 | 首次任务示例 |
|------|-----------|-------------|
| **销售增长官** ⭐ P0 | 客户数据 → 商机报告 | "分析潜在客户机会" |
| **新媒体运营官** ⭐ P0 | 品牌资料 → 内容计划 | "生成一周内容日历" |
| **客服主管** P2 | FAQ → 知识库 | "创建客服知识库" |

### 激活流程

```text
1. 选择岗位模板
2. 输入岗位名称（如"小张-销售增长官"）
3. 配置 LLM API（BYOK）
   - 必须输入自己的 API Key
   - 可选：deepseek / openai / claude / zhipu
4. 系统自动生成 SOUL.md
5. 系统自动绑定 Hermes Profile
6. 完成 → employee.created 事件记录
```

### 验收点

- ✅ EnterpriseAgentInstance 创建成功
- ✅ SOUL.md 已生成
- ✅ Hermes profile 已绑定
- ✅ AI Provider 已配置

---

## Phase 3：渠道授权（2 分钟）

### 授权原则

- **禁止**：人工输入账号密码
- **必须**：OAuth / Token 授权

### 首批渠道

| 渠道 | 授权方式 | 用途 |
|------|---------|------|
| 企业微信 | OAuth | 销售跟进 |
| 公众号 | Token | 内容发布 |
| 抖音 | OAuth | 短视频 |
| 小红书 | OAuth | 种草内容 |
| CRM | API Token | 客户数据 |

### 验收点

- ✅ AgentChannelBinding 创建成功
- ✅ status = active
- ✅ 渠道权限已验证

---

## Phase 4：首次价值确认（5 分钟）

### 触发首次任务

```text
1. 在 AI 员工详情页点击「执行首次任务」
2. 选择任务类型（根据岗位推荐）
3. 确认执行
4. 等待结果（通常 1-3 分钟）
5. 查看 Outcome 报告
```

### 验收点

- ✅ first_task_started 事件已记录
- ✅ first_outcome_created 事件已记录（TTFV 终点）
- ✅ TTFV ≤ 5 分钟
- ✅ Outcome 已落库（OutcomeRecord + ImpactMeasurement）

### 价值案例模板

```
企业: [名称]
员工: [岗位]
结果: [具体业务结果，如"发现50个潜在客户"/"生成7篇内容计划"]
TTFV: [X分钟]
```

---

## Phase 5：7 日复盘

### 检查清单

| 维度 | 指标 | 健康标准 |
|------|------|---------|
| 使用 | AI 员工运行次数 | ≥ 3 次/周 |
| 使用 | 任务数量 | ≥ 5 个/周 |
| 价值 | 节省时间 | ≥ 2 小时/周 |
| 价值 | 增加线索/内容 | ≥ 1 个可量化结果 |
| 风险 | 是否继续使用 | 第 7 天有登录 |

### 风险信号

```
⚠️ 高风险：7天内未执行任何任务
⚠️ 中风险：7天内仅执行1次任务
✅ 健康：7天内执行≥3次任务且有 Outcome
```

## 客户成功团队职责

### 每日

- 检查 TTFV 看板，发现卡住的企业
- 回复企业问题（30 分钟内响应）

### 每周

- 输出《Beta 企业激活周报》
- 识别流失风险企业，主动联系
- 收集产品反馈，汇总给 CTO

### 每月

- 输出《客户成功月报》
- 更新 Onboarding SOP（根据数据反馈）
- 识别最佳实践，复制到其他企业
