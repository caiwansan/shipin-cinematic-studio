## 一、Beta 企业 Onboarding 清单

### 1.1 注册前准备
- [ ] 企业邮箱（非个人邮箱）
- [ ] 企业名称（与营业执照一致）
- [ ] 企业规模（员工数）

### 1.2 注册流程
1. 访问 https://aigc.fushtn.com/enterprise
2. 点击「创建企业数字部门」
3. 填写企业资料（名称、行业、规模）
4. 选择套餐（免费版/专业版/企业版）
5. 绑定支付方式（支付宝/微信）
6. 完成支付 → 订阅激活

### 1.3 激活后 7 天里程碑

| 天数 | 目标 | 验证标准 |
| --- | --- | --- |
| Day 1 | 完成企业资料配置 | 企业信息完整度 ≥ 80% |

| Day 3 | AI 员工执行首次任务 | 至少 1 个 Task 完成 |

| Day 7 | 首次价值复盘 | 填写价值复盘模板 |

## 二、AI 员工首任务模板

### 2.1 P0: 销售增长官（推荐首岗位）

**岗位目标**: 帮助企业找到销售机会

**首任务选项**（三选一）:

#### 选项 A: 客户画像分析
```
任务: 分析我们现有客户数据，输出 Top 10 高价值客户画像
输入: 客户名单 + 交易记录
输出: 客户画像报告（行业、规模、需求特征）
验收标准: 报告包含至少 5 个可行动洞察
```

#### 选项 B: 竞品监控报告
```
任务: 监控 3 家竞品的最新动态，输出周报
输入: 竞品名单 + 监控维度（产品/价格/活动）
输出: 竞品动态周报
验收标准: 每周 1 期，连续 4 周
```

#### 选项 C: 销售话术生成
```
任务: 基于产品特性，生成 5 套销售话术
输入: 产品资料 + 目标客户描述
输出: 话术文档（开场/需求挖掘/异议处理/促成）
验收标准: 销售团队实际使用并反馈

```

### 2.2 P1: 新媒体运营官

**岗位目标**: 提升内容生产效率

**首任务选项**:

#### 选项 A: 内容日历生成
```
任务: 生成下月内容日历（30条）
输入: 产品定位 + 目标平台 + 历史内容
输出: 内容日历（日期/主题/平台/关键词）
验收标准: 内容日历可直接执行
```

#### 选项 B: 爆款标题库
```
任务: 基于行业热词，生成 50 个爆款标题
输入: 行业 + 产品 + 目标用户
输出: 标题库（分类/场景/情绪触发）
验收标准: 至少 10 个标题被实际使用
```

### 2.3 P2: 客服主管

**岗位目标**: 降低客服成本

**首任务选项**:

#### 选项 A: 知识库整理
```
任务: 整理 FAQ 知识库（100条）
输入: 产品手册 + 历史客服记录
输出: 结构化 FAQ（问题/答案/分类）
验收标准: 覆盖 80% 常见问题
```

#### 选项 B: 话术标准化
```
任务: 生成标准化客服话术
输入: 服务流程 + 常见问题
输出: 话术手册（开场/处理/结束）
验收标准: 客服团队采用率 ≥ 60%
```
