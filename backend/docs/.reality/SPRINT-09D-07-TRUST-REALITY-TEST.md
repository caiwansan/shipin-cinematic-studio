## 架构变更总览

### Before
```
buildContext()
 └─ [用户信息] (role="历史档案仅供参考" but named confusingly)
System Prompt
 └─ "你不知道用户的个人信息" (contradicts context packet)
 └─ No claim/fact rules
 └─ No resume safety
```

### After
```
buildContext()
 ├─ [会话中已知信息] (从 history 提取，最高优先级)
 └─ [历史档案 - 仅供参考] (从 DB 读取，标记"不保证现状")

System Prompt
 ├─ 职责 #1: "理解用户真实目标" (vs 机械采集)
 ├─ 身份真实性规则 (Claim vs Fact: 三层)
 ├─ 简历真实性规则 (允许/禁止 + [待补充] + 禁止暗示)
 └─ 上下文使用规则 (AI 应知道已说过的信息)
```
