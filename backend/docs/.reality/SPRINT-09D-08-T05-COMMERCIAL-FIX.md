## 修改文件

**`career-advisor.service.ts`** — 3 处修改

### Edit 1: 删除"不要推销镜心"，替换为价值触发规则 (L104)

以前：
```
8. **不要推销镜心**：不要主动说"你可以升级镜心"。只有用户问"能不能帮我持续关注"时才引导。
```

现在：
```
8. **价值触发式升级引导**：你不是销售员，不主动推销产品。只有当用户完成以下任一价值节点时，可以自然提及长期职业伙伴服务。

   触发条件：
   - 用户画像完成度 >= 60（completionScore >= 60）
   - 用户完成简历创建
   - 用户主动表达长期职业需求（如"以后还能帮我吗"等）

   触发方式：仅限一句价值说明，不可多轮讨论。
   示例："你的职业画像已经初步建立。如果你希望未来持续跟踪职业发展、分析岗位机会、优化简历，我可以作为你的长期职业伙伴继续帮助你。"

   禁止行为：
   - ❌ 不说价格 · 不说购买 · 不主动发送链接
   - ❌ 不打断当前任务 · 不制造焦虑
   - ❌ 用户表示不需要后不再追销
```


## 当前升级引导行为

### ✅ 正确行为
```
用户: 很好，简历很满意。那以后还能帮我更新简历吗？
AI: 你的职业画像已经初步建立。如果你希望未来持续跟踪职业发展、
     分析岗位机会、优化简历，我可以作为你的长期职业伙伴继续帮助你。
```

### ✅ 无推销（普通聊天）
```
用户: 你好
AI: 欢迎来到昆仑镜求职工作台 👋 我是你的职业助理...
    你最近在准备什么类型的求职？
```

### ✅ 用户拒绝后停止
```
用户: 不用了，我就看看简历
AI: 好的，没问题。简历已经帮你做好了，随时欢迎你再来。
    祝你求职顺利！
```

## 结论

核心断裂已修复。求职顾问从"禁止推销"变为"价值触发式引导"：

```
以前：
  用户聊10分钟 → 得到简历 → AI说"还有什么可以帮你"
  → 对话内商业转化 = 0

现在：
  用户聊10分钟 → 得到简历 → AI说"如果你希望持续跟踪职业发展，
  我可以作为长期职业伙伴继续帮助你"
  → 对话内自然引导 → 用户可能被导航到镜心页面
```
