# Sprint-09E-05.2 Cold Start Career Identity Reality

**Date:** 2026-07-31 19:19 CST
**Gate:** ⏳ 待 Reality Test

## 根因

G4 已验证老用户回访场景，但冷启动场景是断裂的：

```
修复前链路:
DB empty → buildCareerAgentContext() throws → identityCard=undefined
→ mergeExtractedFields() 仅内存写入
→ 下一轮 prompt identityCard 仍为空
→ LLM 不知已收集信息 → 重复询问
```

## 修复内容（3 层）

### Layer 1: ConversationCareerState（T02）
新增 `ConversationCareerState` 接口，对话中实时累积事实，不依赖 DB。

### Layer 2: 动态身份卡重建（T03）
每次 `mergeExtractedFields` 后重建身份卡，注入下一轮 Prompt。

### Layer 3: 最低阈值 Draft Profile（T04）
对话收集到最低信息后自动创建 draft CareerProfile。

## 冷启动链路（修复后）

```
对话开始 (DB CareerProfile 不存在)
  ↓
getOrCreateState → careerState = { collectedFields:[], hasMinimumData:false }
  ↓
R1: "软件开发，AI智能体，郑州"
  → extractInfoViaLLM (schema: GREETING → name)
  → mergeExtractedFields (提取技能/城市)
  → syncProfileToCareerState → careerState = { collectedFields:['skills'] }
  → updateConversationIdentityCard → identityCard = { skills:['软件开发','AI智能体'] }
  → generateReplyViaLLM (Prompt 包含对话身份卡)
  ↓
R2: "10年软件开发"
  → extractInfoViaLLM (yearsOfExperience:10)
  → syncProfileToCareerState → hasMinimumData = true
  → checkMinimumDataThreshold → 创建 draft CareerProfile!
  → updateConversationIdentityCard → identityCard = { skills, exp:10, direction }
  → generateReplyViaLLM (Prompt: "李雷，你10年开发...")
  ↓
R3: "LangChain，本科，软件工程"
  → extractInfoViaLLM (skills + education)
  → syncProfileToCareerState → collectedFields 扩展
  → updateConversationIdentityCard → 身份卡全量
  → generateReplyViaLLM (Prompt: 全量身份注入)
```

## 关键区别

| 场景 | 修复前 | 修复后 |
|------|--------|--------|
| 冷启动用户 R1→R5 | identitySection=空 → 重复问 | identityCard 迭代积累，不重复 |
| 老用户新会话 | identityCard 从 DB 加载一次 | identityCard 加载 + 对话新事实合并 |
| DB 写入时机 | 阶段推进或 COMPLETE | 最低阈值即创建 draft |
| Prompt 注入 | identityCard (DB 静态) | conversationIdentityCard (对话最新) |
