## 背景结论（已验收）

> 混沌珠小说工作台已从"AI 写作系统"进入"AI 长篇小说生产系统"阶段。
> 本轮最大价值不是 Reality Score 92→99，而是建立了**生产度量闭环**：

```
生产任务 → 成本记录 → 质量评分 → Reality Checkpoint → 优化决策
```

这是商业 SaaS 的数据闭环，是从工具到平台的分界线。

## 核心指标（固化，不覆盖历史）

| 指标 | 当前值 | 定位 |
|------|--------|------|
| 累计成本 | ¥3.86（146 次调用） | 成本基线 |

**优化方向（已确认）**：不追求"最低成本生成"。商业用户会选 ¥0.3/千字 + 95 分，不选 ¥0.2/千字 + 70 分。目标永远是提高 `Reality Score ÷ 成本`。

## 队列压力 — 架构暴露（暂不改造）

```
queued=82 | running=12/2 | 平均等待 532s
```

实际执行模型 = Worker(2) + 链式直调 + 事件提取 + reviewer + memory update 的**隐性并发**，
已超过原始 concurrency=2 设计。这是百万字生产必经问题。

**决策：ch24 数据不足，现在不改。** 观察至 ch50：

| 观察指标 | 恶化信号 | 触发动作 |
|----------|----------|----------|
| 平均等待时间 | 持续增长 | 进入 HDZNOVEL-REALITY-03 |
| 任务积压趋势 | queued 持续 > running×50 | 动态生产调度 |
| 单章完成时间 | 持续拉长 | 优先级队列分级 |

可能方案（ch50 后）：优先级队列分级 `chapter_generation > review > memory > event_extract`，
**不要让事件提取堵住正文生产**。

## ch50 Reality Checkpoint — 三查清单

### 查人物
- [ ] 性格突然变化（无铺垫的 180° 转变）
- [ ] 决策违背初心（与角色弧线矛盾）
- [ ] 心理漂移：高危突变（high/critical）是否都有 recoveryChapter

### 查世界
- [ ] 势力关系错误（结盟/敌对反转未记录）
- [ ] 修炼规则破坏（力量体系前后矛盾）

### 查伏笔
- [ ] 提前泄露（应现章节前正文已暴露）
- [ ] 忘记回收（应现伏笔正文未提及 → 5-gram 滑窗检测）
