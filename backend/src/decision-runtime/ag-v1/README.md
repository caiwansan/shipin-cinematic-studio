# AG-V1 评测层 — 系统能力验证框架

## 核心问题
连续七层 AG（2→5）叠加后，所有判断都是"看起来合理"而非"客观变好了"。
AG-V1 的目标是建立第一条可信的测量基线。

## 四个子阶段
- V1.1: Benchmark Dataset（200 条标准测试集）
- V1.2: Metrics Framework（统一指标）
- V1.3: Replay Runner（自动化回放）
- V1.4: Regression Gate（回归检查）
