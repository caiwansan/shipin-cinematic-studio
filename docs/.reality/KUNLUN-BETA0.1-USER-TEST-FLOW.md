# 昆仑镜 Beta 0.1 — 真实用户体验测试流程（非开发人员）

> 配套: KUNLUN-BETA0.1-WINDOWS-REALITY-REPORT.md（Task 03）
> 用途: 第一个非开发用户的测试引导（禁介绍 AI 平台/LLM/Agent/Runtime/Framework 等系统语言, 只允许「你的 AI 员工团队」）

---

## 0. 测试准备

```
账号: 测试企业用户（tenant_org_test@audit.local / AuditTest@123）
企业: 昆仑镜验收测试企业（已授权 Alice + 短剧 + 新媒体 + 法务 + 财务）
机器: Windows 真机（RG-W2 安装完成后）
引导人: 只做环境准备, 不做产品讲解
```

## 1. 第 5 分钟（首次理解）

### 流程
```
打开昆仑镜 → 登录（引导人输入账号）→ 观察首页
```

### 观察（不提示）
| 问题 | 期望 |
|---|---|
| 用户第一句是什么？ | 「这是我的 AI 团队？」 |
| 能否说出有哪些员工？ | 5 个员工卡 |
| 能否说出员工负责什么？ | 「招聘/内容/法务…」 |
| 会主动点什么？ | 员工卡/去商城/快捷动作 |

### 5 分钟理解测试
```
问: 「你觉得昆仑镜是什么？」
期望: 「一个 AI 员工团队/我的 AI 公司」
失败信号: 「聊天机器人」「AI 工具网站」
```

## 2. 引导一个真实任务（只演示一次）

```
引导语（只允许）: 「让 Alice 帮你看看这个岗位」
步骤: 打开 Alice → 安排任务（进入工作台）→ 招聘需求
期望: 用户看到「员工在干活」（简历解析→评分→面试评估→报告）
```

## 3. 第 2 天（回访）

```
观察: 是否主动打开 Desktop / 是否再次调用 Alice
问: 「昨天那个员工好用吗？」
记录: 主动使用次数 / 卡点
```

## 4. 第 7 天（习惯形成）

```
观察: 是否形成固定任务习惯（HR 每天找 Alice / 内容团队找导演 / 管理者看企业中心）
问: 「如果下个月没有这个 AI 员工, 会不会觉得少了什么？」
价值验证: 「会」→ 299/999 定价有意义
```

## 5. 反馈收集（用户语言, 禁技术词）

```
1. 你最喜欢哪个员工？为什么？
2. 哪个地方让你困惑？
3. 你希望 AI 员工帮你做什么（现在还没有的）？
4. 如果付费, 你愿意为什么付？
```

## 6. 成功标准

```
✅ 第 5 分钟: 理解「我有 AI 员工团队」
✅ 第 2 天: 主动打开
✅ 第 7 天: 固定使用某个员工
✅ 价值: 「少了一个同事」的感觉
→ 达到 = 昆仑镜跨过工程→产品门槛
```
