**Beta 实施范围**: 1 + 2 + 4（纯 Desktop 壳层, 零 Nuxt 触碰, 零新后端 API）

## 1. 第一分钟体验（Beta）

```
触发: 首次登录（本地无「已见欢迎」标记）
流程: 登录成功 → 欢迎引导层覆盖首页 →
  ①「欢迎来到昆仑镜」
  ②「这是你的 AI 团队」→ 5 员工卡片（头像/定位/一句话）
  ③「下一步」→ 应用商城（浏览员工） / 「直接开始」（进入首页）
记忆: localStorage kl_welcomed=1（再次登录跳过）
体验目标: 像 Mac「欢迎使用」, 不是直接丢桌面
```

## 2. AI Employee 数字员工档案（Beta）

```
详情视图升级（现有详情基础上补）:
  顶部: 头像（玉牌）+ 定位（24h 价值表达）+ 状态点（在线/待授权）
  今天状态: 今日完成 N 个任务（usage 当日? 用累计+成功率, 零新 API）
  负责: ✓ 清单（landing.responsibilities）
  最近成果: 最近执行（usage.recent → 资产类目文案）
  动作: [安排任务→启动工作台] [查看详情→能力/增强/用量完整]
用户感: 不是买软件, 是雇佣员工
```

## 3. 工作空间三栏统一（S8.3, 设计冻结）

```
依赖: Nuxt 工作台视觉重构（Desktop 壳层不承载）
规格（冻结, 供 S8.3）:
  左栏 员工身份 / 中栏 任务流 / 右栏 成果资产
  参考: ChatGPT + Notion + Photoshop 工作区
```

## 4. Command Center（Beta, 最小版）

```
快捷键: Ctrl+Space（Windows）/ Cmd+Space（macOS 后续）
面板: 居中浮层（宣纸白, 天青描边）, 输入即搜
动作（消费现有 API）:
  - 搜员工: marketplace/employees（q 过滤）→ 回车 = 打开档案
  - 快捷启动: 输入员工 code → 启动工作台
  - 直达: 「用量」「企业管理」「应用商城」「设置」
  - 展示: 结果列表（印章徽章 + 一行说明）
边界: 纯壳层 UI + 现有 API; 无 AI 问答（正式版）
```

## 5. Windows 原生体验（正式商业版, 记录）

```
系统托盘（最小化到托盘/常驻）/ 开机启动选择 / 通知中心
更新提示（updater）/ 离线状态横幅 / 网络恢复自动重连 / 崩溃恢复（诊断模式已有, 补自动上报开关）
Beta 0.1 不做（掌柜: Beta 可以简单）
```

## 6. Reality Gate（PX1-PX6, 待 Phase B）

| # | 关卡 | 验证 |
|---|---|---|
| PX1 | 第一分钟引导 | 首次登录显示欢迎层; 再次登录跳过; 「建立 AI 团队」5 员工数据真实 |
