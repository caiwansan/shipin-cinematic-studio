# KUNLUN-S8.0-DESKTOP-EXPERIENCE-DESIGN.md

> S8.0 Desktop Experience Design Freeze — 东方未来主义 AI OS 视觉与交互规范
> 日期: 2026-08-06 21:30 (CST) | 状态: ✅ **设计冻结, 待掌柜批准 S8.1 实现**
> 依据: 掌柜补充修正（功能已通电, 但应用层 UI/UX 未进设计; 方向 = 中国传统配色 + 雨后天青 + 青花瓷 + 东方未来主义; 目标接近 macOS 克制/Linear 极简/Arc 空间感/Notion 工作流/宋瓷美学）
> 定位: **把已有能力包装成世界级 AI OS 产品第一印象（非增加功能）**

---

## 0. 设计总纲（东方未来主义）

```
不是国风软件: 东方符号 + 现代几何（Apple 不画苹果树, 昆仑镜不画龙凤）
克制: 信息密度低, 留白充足, 层级清晰
空间: 像走进一座中式庭院, 每个房间（页面）有明确功能
情绪: 晨雾青山 / 天青釉 / 宣纸 —— 安静、可信、高级
```

## 1. Desktop 信息架构（冻结）

```
┌──────────────────────────────────────┐
│ 昆仑镜 AI OS                          │
│ ───────────────────────────────────── │
│  侧栏（72px 图标栏 + 展开 200px）      │
│  首页（Home）         ★ 默认落地       │
│  AI 员工（Employees）                  │
│  应用商城（Marketplace）               │
│  企业中心（Enterprise）                │
│  工作空间（Workspace）                 │
│  插件（Plugins）                       │
│  设置（Settings）                      │
│ ───────────────────────────────────── │
│  底部: 账户头像 + 企业徽章             │
└──────────────────────────────────────┘
层级: 全局侧栏 → 页面（列表）→ 详情（抽屉/子页）→ 操作（模态）
```

## 2. 首页设计（AI 员工办公室入口, 冻结）

```
视觉: 晨雾青山渐变背景（天青 → 宣纸白, 顶部 1/3 山影 SVG 极简线条）
文案: 「你的 AI 团队今天准备好了」+ 企业名 + 日期（农历可选: 八月初七）

员工状态卡（横向滚动）:
  [🟢 Alice · 招聘经理 · 今日完成 12] [🟢 导演 · 内容生产] [🟢 新媒体] [🟢 法务] [🟢 财务]
  卡片 = 员工档案式（非工具按钮式）: 头像（印章风）/ 角色 / 状态点 / 今日完成数

今日任务（时间线）: 最近执行计划 + 状态
最近成果（资产流）: 最近生成报告/分析（candidate-report/分镜/内容/合同/财务）
快捷动作: 「给 Alice 一个新招聘需求」「让导演分析剧本」
```

## 3. AI Employee 设计语言（员工档案式, 冻结）

```
不是: [AI招聘助手] [启动]
而是: 员工档案
  ┌────────────────────────────┐
  │ Alice（玉牌头像 + 印章徽章） │
  │ 你的 24 小时招聘经理         │
  │ 状态: 🟢 在线 · 已授权       │
  │ ──────────────────────────  │
  │ 负责: ✓ 简历分析 ✓ 人才画像  │
  │       ✓ 候选评分 ✓ 面试辅助  │
  │ 今日完成: 12 个任务          │
  │ 最近成果: 候选人分析报告 3 份 │
  │ [进入工作台] [详情]          │
  └────────────────────────────┘
状态色: 🟢 在线(已授权) / ⚪ 待授权 / 🟡 试用
```

## 4. Marketplace 设计语言（冻结）

```
商品卡升级: 印章式分类徽章（人力=朱红印/内容=天青印/营销=黛蓝印/风险=墨色印/财务=金印）
卡片: 留白 + 细线框（1px #E5E0D3）+ 圆角 12px + 悬停微抬升
详情页: 左品牌区（人物化插画/印章）+ 右信息区（适合/负责/能力/增强/用量）
搜索: 顶栏圆角输入, 搜索时山影淡出
分类 tab: 印章风格 pill（选中 = 填充天青 + 白字）
```

## 5. Enterprise Center 设计语言（冻结）

```
企业控制台: 宣纸底色 + 数据卡片（白底细框）
套餐徽章: 金色印章（Enterprise 级）——金色仅用于 VIP/认证/高级态
员工用量: 条形图（天青渐变）+ 成功率环形（细线）
成员列表: 玉牌头像（首字）+ 角色标签
克制: 数字不堆砌, 每卡片一个核心指标
```

## 6. 色彩系统（冻结, 令牌化）

```
主色  雨后天青   #7BA7A3   （品牌/主按钮/选中态/链接）
辅助  青花瓷蓝   #24527A   （深色文字/图表/信息层级）
背景  宣纸白     #F7F5EF   （页面底色）
强调  金色印章   #C8A951   （VIP/企业认证/高级员工/权限——少量）
文字  墨色       #2B2B28   （主文）  #6B6A63（次文）
边框  细线       #E5E0D3
成功  #4A7C59 / 警告 #C8A951 / 错误 #A94442（低饱和, 不刺眼）
令牌: --kl-primary/--kl-deep/--kl-paper/--kl-gold/--kl-ink/--kl-ink-sub/--kl-line
暗色（后续）: 黛蓝底 #1E2430 + 天青点缀
```

## 7. 组件系统（冻结）

```
导航: 侧栏图标（几何化东方符号: 山/印/卷/阁/扇/盒/齿）+ 文字, 选中 = 天青左侧条 + 图标填充
卡片: 白底/1px 细线/12px 圆角/16px 内边距/悬停 translateY(-2px)+shadow 1px
徽章: 印章式（细边 + 圆角 4px + 文字小号）; 分类徽章带色
按钮: 主=天青填充白字; 次=白底细边墨字; 禁用=宣纸灰; 圆角 8px
状态点: 8px 圆点（在线/待授权/试用/离线）+ 呼吸动效（在线）
头像: 玉牌/印章几何插画（首字+色块）, 非真人图
输入: 宣纸白底 + 细线 + 聚焦天青描边
加载: 天青细线进度条 + 山形 skeleton
```

## 8. 动效规范（冻结, 克制）

```
原则: 克制动效（参考 macOS/Linear）; 100-200ms; 无弹跳无夸张
页面切换: 120ms fade + 8px 上移（视差山影 200ms 更慢, 营造层次）
卡片悬停: 80ms 抬升 + 阴影过渡
状态点: 在线呼吸 2.4s 循环（opacity 0.6-1, 不闪烁）
加载: 细线进度 400ms 循环; 骨架 600ms 呼吸
滚动: 惯性 + 顶栏毛玻璃（backdrop-filter, 宣纸白 80%）
禁用: 不允许动效（尊重减少动态偏好, prefers-reduced-motion）
```

## 9. Windows/macOS 适配规范（冻结）

```
窗口: 默认 1280x800 / 最小 1024x680; Windows 圆角 8px 标题栏（深色模式适配）
字体: 中文 思源黑体（Noto Sans SC）/ 西文 Inter; 标题 600 字重, 正文 400; 字号 13-20 阶梯
缩放: 支持 100%-150% DPI（rem 单位）
深浅色: 浅色默认; 跟随系统（暗色 = 黛蓝底 #1E2430 + 宣纸文字反转）
滚动条: 细 6px 圆角, 悬停显现（Windows 默认样式覆盖）
触控板: 支持两指返回（历史栈）/ 捏合缩放（禁用页面缩放, 仅系统）
macOS（未来）: 标题栏透明 + 侧栏 vibrancy; 本阶段 Windows 优先
```
