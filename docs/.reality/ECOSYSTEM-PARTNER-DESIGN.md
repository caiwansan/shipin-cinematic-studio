## 一、设计原则（掌柜红线 + 技术总监确认）

1. **收入必须来自真实插件订阅收入（真实 GMV）。**
2. **禁止拉人头奖励**（无发展下线奖励、无入门费、无层级计酬、无团队人数奖励）。
3. **模式正式命名：SaaS Affiliate + Partner Revenue Share**（联盟推广 + 伙伴收入分成），明确排除 MLM（多层次直销）模式。
4. 推广伙伴赚的是**自己推广产生的订阅流水分成**，不是发展人数。

---

## 二、生态伙伴等级体系

| 等级 | 晋升条件（示例） | 市场生态分成 | 权益 |
|------|-----------------|-------------|------|
| 普通推广伙伴 | 注册即得 | 10% | 推广链接/码、收益看板 |
| 生态推广伙伴 | 近 90 天推广业绩 ≥ ¥5,000 | 15% | 专属物料、优先客服 |
| 区域生态伙伴 | ≥ ¥50,000 | 20% | 区域联合活动、定制方案 |
| 城市生态伙伴 | ≥ ¥200,000 | 25% | 城市合伙人证书、线下支持 |
| 省级生态伙伴 | ≥ ¥800,000 | 30% | 省级独家授权、联合品牌 |
| 平台生态合伙人 | ≥ ¥3,000,000（或战略合作） | 36%（上限） | 定制产品、联合研发 |

- 等级**只与推广业绩挂钩**，与团队人数无关。
- 等级每季度复核（滚动 90 天业绩），只升不降保护期一个季度。

## 三、业绩计算规则（小区业绩）

### 3.1 定义

```
小区业绩（个人推广业绩） =
    团队总业绩（推广网内所有伙伴产生的订阅流水）
  - 最大业绩线（直推伙伴中业绩最大的一支线）
```

### 3.2 为什么用小区业绩

- 防止「单一大团队把业绩全部挂在一人头上」的传销式结构。
- 确保每一层伙伴的收入与其**实际推广贡献**匹配，而不是与其「下线人数」匹配。
- 规则透明、可审计：任何一笔业绩可追溯到具体订阅订单。

### 3.3 计算示例

```
合伙人 A 推广网：
  直推 B（业绩 ¥100,000）、直推 C（业绩 ¥60,000）、个人业绩 ¥40,000
  团队总业绩 = ¥200,000
  最大业绩线 = ¥100,000（B 线）
  小区业绩 = ¥200,000 - ¥100,000 = ¥100,000
  → A 的市场分成 = ¥100,000 × 36%（合伙人档）= ¥36,000
```

### 3.4 防套利规则

- 业绩 = 实收订阅流水（扣除退款/拒付），非标价。
- 自购自推不计业绩（同一实名主体）。
- 业绩产生时点 = 订阅扣款成功且过退款期（7 天）后入账。
- 每月结算：生成 Settlement 结算单，明细到订单级。

## 四、数据模型

```
PartnerNode          推广节点
  ├── userId / orgId
  ├── parentId（推广关系树，仅一层直推记录）
  ├── level（伙伴等级）
  ├── partnerCode（专属推广码）
  └── status

PartnerPerformance   业绩记录
  ├── partnerId
  ├── period（月份）
  ├── teamVolume（团队总业绩）
  ├── maxLineVolume（最大业绩线）
  ├── cellVolume（小区业绩）
  ├── settledVolume（已结算业绩）
  └── levelAtPeriod（当期等级）

PartnerReward        奖励记录
  ├── performanceId
  ├── rewardAmount（本期分成）
  ├── shareRate（当期分成比例）
  └── status（pending/settled）

Settlement           结算单
  ├── partnerId / period
  ├── detail（订单级明细 JSON）
  ├── amount / tax / channelFee
  ├── payoutMethod / status
  └── paidAt
```

## 五、推广链路（防作弊）

```
用户 → 点击伙伴推广链接（带 partnerCode）
  → 注册/登录（首次绑定伙伴关系，Cookie/参数 + 设备指纹）
  → 安装插件 → 订阅付费（RevenueRecord 标记推广来源）
  → 过退款期 → 业绩入账（PartnerPerformance）
  → 月度结算（Settlement）
```

**防作弊**：
- 自推自购排除（实名主体 + 设备指纹匹配）。
- 关系绑定 30 天有效（过期后自然流量归平台）。
- 异常检测：同一 IP 批量注册、异常退款率、刷单模式 → 冻结结算 + 人工审计。

## 六、合规红线（明确禁止）

| 禁止项 | 说明 |
|--------|------|
| 拉人头奖励 | 发展人数不计酬 |
| 入门费/会员费 | 推广伙伴注册免费 |
| 层级计酬 | 只按推广业绩（小区业绩）计酬，不按层级 |
| 团队计酬 | 收入只来自自己推广网的订阅流水，非团队人数 |
| 虚假宣传 | 伙伴物料需平台审核，禁止承诺收益 |

## 七、风险清单

| # | 风险 | 缓解 |
|---|------|------|
| 1 | 推广体系滑向传销 | 小区业绩 + 实名 + 禁止拉人头 + 法务审核 |
| 2 | 刷单套利 | 退款期后入账 + 设备指纹 + 异常检测 |
| 3 | 平台分成被佣金侵蚀 | 市场生态上限 36%，平台保底 10% |
| 4 | 伙伴流失 | 等级保护期 + 物料支持 + 结算透明 |
