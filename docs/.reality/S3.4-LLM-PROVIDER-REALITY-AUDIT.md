## 2. Gateway Invoke Path（invokeAI 流程）

```
invokeAI(envelope)
  → gatewayGuard（内存速率/并发限制）
  → userModelResolver.resolve(capability, userId)   ← BYOK V2
  → null → failEnvelope("用户未配置模型")           ← 硬失败, 无平台默认 fallback
  → 选 adapter（aliyun/volcengine/deepseek/openai）
  → 执行（超时 30s + 重试 2 次）
  → InvocationLog 审计
```

关键事实：**gateway 无平台默认 Key fallback**——`resolve()` 返回 null 即失败。
