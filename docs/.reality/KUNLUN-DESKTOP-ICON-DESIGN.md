```
tauri.conf.json bundle.icon:
  ["icons/32x32.png", "icons/icon.png", "icons/icon.ico", "icons/icon-1024.png"]
  ↓
Tauri 构建期: icon.png → 主 exe 资源; icon.ico → Windows exe/窗口/任务栏
  ↓
NSIS bundle.windows: 无显式 icon 覆盖 → 继承 tauri.conf icon.ico
```

- **加载链路完整**：单一来源（tauri.conf.json icon 数组）→ 全平台派生，无分散引用
- **缺口**：无 `bundle.windows.nsis.installerIcon` / `uninstallerIcon` 显式配置（Tauri v2 支持独立安装器图标，当前未用）

## 1. 品牌定位

**昆仑镜 = 企业 AI 员工操作系统**

第一身份信号必须回答："这是什么"——不是聊天软件，不是浏览器壳，而是**管理 AI 员工团队的企业系统入口**。

### 品牌语义拆解

| 元素 | 含义 | 视觉转译 |
|---|---|---|
| 昆仑 | 东方科技山脉 | 山形/层峦/脊线，稳重、根基 |
| 镜 | 智能中枢/观察/连接 | 圆形/镜面/聚焦点，洞察、中枢 |
| AI Core | 未来计算 | 芯片网格/光点/脉冲，智能化 |
| 企业可靠性 | 可信、专业 | 对称、克制、深色底、金色点缀 |

### 明确排除

- ❌ 聊天气泡 / 对话窗口图形（会把产品认知拉向聊天工具）
- ❌ 龙/凤/祥云/水墨山水插画（过度国潮，偏离"企业 SaaS"定位）
- ❌ 纯文字 Logo（小尺寸不可读）
- ❌ 复杂插画 / 游戏风格 / 拟物 3D

## 2. 三套图标设计方案

### 方案 A —「昆仑镜面」（推荐）

**设计理念**：一座抽象的山形置于圆形镜面之中，镜面上方一点金色光点 = AI Core 正在"照见"企业。

```
    ● (金色 AI 光点, 天青环)
   / \      ← 山形 = 昆仑 (天青 #7BA7A3 渐层)
  /   \     ← 镜面圆形边界 (深青 #24527A)
 /  ▦  \    ← 山体中嵌入芯片网格 (AI Core)
```

- **图形结构**：圆形外框（镜）→ 内部三层山脊（昆仑）→ 山体中心 4×4 微网格（计算核心）
- **色彩方案**：宣纸白底圆角方（App 容器）＋ 青花瓷蓝镜环 + 雨后天青山体 + 金印光点（仅 1 处点缀）
- **品牌含义**：镜 = 中枢；山 = 东方根基；光点 = AI；网格 = 企业计算——四义合一
- **小尺寸策略**：32px 时保留「圆 + 山 + 光点」三要素，网格隐去（尺寸自适应降级）

### 方案 B —「芯片昆仑」

**设计理念**：抽象芯片轮廓（圆角方形 + 引脚）内嵌山形，强调"AI 硬件级计算平台"。

- **图形结构**：圆角方形芯片（企业感）→ 四边短引脚（计算）→ 中央山形负空间
- **色彩方案**：深墨蓝底 (#1E2A3A) + 天青山形发光 + 金色中心点
- **品牌含义**：企业级 AI 基础设施；偏"算力平台"感知
- **风险**：芯片图形易与"硬件/半导体"混淆，AI 员工系统感知弱于方案 A

### 方案 C —「双镜回环」

**设计理念**：两个交叠圆环（镜子对视 = 观察/连接），交点处一颗金色核心。

- **图形结构**：双环交叠（∞ 意向）→ 交点金色光核 → 环带天青/深蓝双色
- **色彩方案**：天青环 + 深蓝环 + 金核
- **品牌含义**：连接（企业与 AI、云与端、镜与镜）
- **风险**：双环图形在 32px 易糊；"连接"语义偏网络工具，企业 AI 员工感弱于方案 A

### 推荐

**方案 A「昆仑镜面」**——唯一同时满足：
1. 东方品牌（山/镜）✅
2. AI 感知（光点/网格）✅
3. 企业可信（对称/克制/深色+金点缀）✅
4. 小尺寸可识别（三要素降级策略）✅
5. 不与聊天/浏览器/游戏混淆 ✅
