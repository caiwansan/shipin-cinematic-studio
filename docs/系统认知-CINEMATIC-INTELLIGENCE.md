# 🎬 Cinematic Studio 系统认知文档

> **AI 电影导演系统 / AI 电影创作工作台**
> 核心资产不是视频生成能力，而是**电影理解能力（Cinematic Intelligence）**

---

## 一、真实工作流（正确抽象）

```
用户创意
    ↓
OMS 世界建模（叙事意图 → 世界/角色/情绪/冲突/镜头/节奏）
    ↓
粒子语义场（电影语言的物理化表达——情绪扩散/角色聚合/冲突裂变/运镜轨迹）
    ↓
C2V 翻译层（将世界状态翻译成视频模型能理解的视觉指令）
    ↓
视频模型生成真实画面（Volcengine / Diffusion / Transformer Video Model）
    ↓
反馈学习（OMS 分析崩坏/导演意图/镜头/情绪 → 优化 Prompt 和导演策略）
    ↓
导演系统进化
```

---

## 二、核心架构职责划分

### 🧠 OMS = 电影思维系统（Cinematic Brain）
负责：
- 世界理解与构建
- 叙事意图解析
- 运镜决策
- 节奏控制
- 情绪曲线
- 导演决策

### 🎥 视频模型 = 视觉渲染器（Visual Renderer）
负责：
- 真实画面生成（光影/材质/运动）
- 人脸与细节
- 电影感画面输出
- 像素级视频渲染

### 🌌 粒子系统 = 视觉语义模拟层（Visual-Semantic Simulation Layer）
不是最终视频，而是：
| 粒子行为 | 代表语义 |
|---------|---------|
| 扩散 | 情绪增强 |
| 聚合 | 角色接近 |
| 裂变 | 冲突爆发 |
| 轨迹 | 运镜方向 |
| 湍流 | 紧张感 |
| 光晕 | 主角聚焦 |

## 三、关键认知修正

### ❌ 错误说法
- "宇宙粒子生成视频"
- "AI视频工具"
- 用户 → prompt → 视频

### ✅ 正确说法
- **OMS 负责「理解电影」，视频模型负责「渲染电影」**
- **AI 电影导演系统 / AI 电影创作工作台**
- **用户 → 世界 → 导演 → 镜头 → 视频**

---

## 四、差异化优势

大多数 AI 视频产品：
```
用户 → prompt → 视频
```

Cinematic Studio：
```
用户 → 世界 → 导演 → 镜头 → 视频
```

这带来的核心价值：
- **长视频更稳定** —— 世界模型提供叙事连贯性
- **多镜头更一致** —— 角色/场景/情绪在镜头间保持一致
- **角色更连续** —— 有角色记忆和性格约束
- **情绪更像电影** —— 有节奏曲线、冲突推演、导演决策

## 五、真实流水线（Pipeline）

| 阶段 | 名称 | 职责 |
|------|------|------|
| 1️⃣ | 叙事意图输入 | 用户输入 → 叙事意图（Narrative Intent），不是简单 prompt |
| 2️⃣ | OMS 世界构建 | Field → World → Drama → Director（电影预制作 Pre-production） |
| 3️⃣ | 粒子语义模拟 | 电影语言的物理化表达，作为 C2V 翻译层的输入 |
| 4️⃣ | C2V 翻译层 | OMS 状态 → 视觉语义 → Prompt / Shot / Frame Plan |
| 5️⃣ | 视频生成 | 火山引擎 Seedance 等视频模型渲染真实画面 |
| 6️⃣ | 反馈学习 | 导演策略优化，OMS 系统自我进化 |

---

## 六、对外定位

> **「AI 电影导演系统」**
>
> 不是做 "AI 生成视频" 的工具，
> 而是做 "理解电影、导演电影" 的智能系统。
