### 4.3 数据流原则

```
Page → Store → Service → API

禁止:
  ❌ Page 直接 fetch('/api/...')
  ❌ Page 直接调用 prisma
  ❌ Store 不经过 Service 直接请求

正确:
  ✅ Page 调用 Store Action
  ✅ Store Action 调用 Service Method
  ✅ Service Method 调用 API
  ✅ API 返回数据 → Service 转换 → Store 更新 → Page 响应
```
