## 产品架构（冻结）

```
Platform AI Control Plane (AI Center)
  ├── Provider 管理 (DeepSeek, OpenAI, Qwen, Gemini, Claude, 本地模型…)
  ├── Credential 管理
  ├── 默认模型 / 模型路由
  ├── 连接状态 / 健康检查
  └── 未来: 视频模型 / 音乐模型 / Embedding / Reranker / MCP Server

  ├── 短剧
  ├── 小说
  ├── PPT
  ├── 音乐
  └── 未来工作台
```

## 平台设计原则（冻结）

> **"工作台负责生产 AI，平台负责管理 AI。"**

Workspace 不管理的职责:
- ❌ API Key / Credential
- ❌ Provider 配置
- ❌ 模型设置
- ❌ 会员中心
- ❌ 用户资料

Platform AI Center 管理的职责:
- ✅ Provider & Credential
- ✅ 默认模型 & 路由
- ✅ 连接状态 & 健康
- ✅ 未来 AI 能力扩展

## 产品通用原则

> Workspace 负责创作、分析、生成等业务流程。Platform 负责模型、凭证、Provider、路由、能力配置等平台治理。
