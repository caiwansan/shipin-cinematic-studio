## 一、Goal

Enterprise Intelligence 已具备 Observe → Understand → Decide → Act → Govern，但缺少最后一环：**Learn**。

目标：

> Action → Outcome → Impact → Decision Feedback Loop

**范围（CTO 明确）：** Structured Outcome + Impact Framework + Decision Feedback  
**范围外（CTO 明确）：** ❌ Revenue Attribution（无真实数据源） ❌ Channel Adapter

## 二、5 Frozen Contracts（开发前冻结）

### Contract 1: Outcome Entity

```typescript
interface Outcome {
  id: string  
  actionId: string  
  governanceTenantId: string

  status: SUCCESS | FAILED | PARTIAL
  summary: string          
  evidence: EvidenceItem[]  
  occurredAt: Date

  createdAt: Date
}

interface EvidenceItem {
  type: string               
  url: string | null
  description: string
  attachedAt: Date
}
```

**关键字段：**
- `actionId` → 关联 Action
- `status` → 三种明确状态
- `evidence[]` → 结构化证据链（替代纯文本 `executionResult`）

---

### Contract 2: Action → Outcome Relationship

- **One Action → Outcome（1:1）**
- Action `COMPLETED` / `FAILED` 时必须创建 Outcome
- Outcome 不可独立于 Action 存在

```prisma
model EnterpriseOutcome {
  id                  String    @id @default(dbgenerated("gen_random_uuid()::text")) @db.Text
  tenantId            String    @map("tenant_id") @db.Text
  governanceTenantId  String?   @map("governance_tenant_id") @db.Text
  actionId            String    @map("action_id") @db.Text @unique

  status              String    @default("PENDING_VERIFY") @db.Text
  summary             String?   @db.Text
  evidence            Json      @default("[]")
  occurredAt          DateTime? @map("occurred_at")

  // Feedback
  confidenceDelta     Int?      @map("confidence_delta")
  impactType          String?   @map("impact_type") @db.Text
  impactLevel         Int?      @map("impact_level")

  createdAt           DateTime  @default(now()) @map("created_at")

  action              EnterpriseAction @relation(fields: [actionId], references: [id], onDelete: Cascade)

  @@index([tenantId])
  @@index([governanceTenantId])
  @@index([actionId])
  @@index([status])
  @@index([impactType])
  @@map("enterprise_outcome")
}
```

### Contract 3: Outcome Status Contract

```
Action.Status        → Outcome.Status
─────────────────────────────────────
COMPLETED            → PENDING_VERIFY (用户声明成功)
FAILED               → FAILED (执行失败)
```

Outcome 内部生命周期：

```text
PENDING_VERIFY  → VERIFIED    (人工确认)
PENDING_VERIFY  → REJECTED    (人工驳回)
FAILED          → 不需确认
```

**CTO 冻结：** Outcome 状态不允许自动流转。

---

### Contract 4: Impact Framework

四种 Impact 类型（先枚举，不强行量化）：

```typescript
type ImpactType = 'operational' | 'engagement' | 'conversion' | 'revenue'

interface Impact {
  type: ImpactType    
  level: 1 | 2 | 3 | 4 | 5    
  description: string
  source: 'manual' | 'system'  // CTO: 禁止假装系统采集
}
```

- `operational` — 流程效率提升（示例：客服效率+30%）
- `engagement` — 互动指标（示例：素材打开率提升）
- `conversion` — 转化指标（示例：线索提交数增加）
- `revenue` — 收入（真实数据源接入前禁止填充）

---

### Contract 5: Decision Feedback

Outcome 结果 → Decision Confidence 反馈：

```typescript
interface DecisionFeedback {
  recommendationId: string
  actionId: string
  outcomeId: string
  previousConfidence: number  // Example: 80
  adjustedConfidence: number   // Example: 65
  adjustmentReason: string
  feedbackType: 'learn' | 'boost' | 'warn'
}
```

- 成功 Outcome → 相似 Decision confidence +5
- 失败 Outcome → 相似 Decision confidence -15
- **CTO 冻结：** 反馈是参考，不自动改变 CEO 决策。SSOT 是 CEO。

## 三、Technical Design

### 3.1 Database Changes

```sql
-- enterprise_outcome table
CREATE TABLE enterprise_outcome (
  id                    TEXT PRIMARY KEY DEFAULT gen_random_uuid()::text,
  tenant_id             TEXT NOT NULL,
  governance_tenant_id  TEXT,
  action_id             TEXT NOT NULL UNIQUE,
  status                TEXT NOT NULL DEFAULT 'PENDING_VERIFY',
  summary               TEXT,
  evidence              JSONB NOT NULL DEFAULT '[]'::jsonb,
  occurred_at           TIMESTAMPTZ,
  confidence_delta      INTEGER,
  impact_type           TEXT,
  impact_level          INTEGER,
  created_at            TIMESTAMPTZ NOT NULL DEFAULT NOW(),

  CONSTRAINT fk_action FOREIGN KEY (action_id) REFERENCES enterprise_action(id) ON DELETE CASCADE
);

CREATE INDEX idx_outcome_tenant ON enterprise_outcome(tenant_id);
CREATE INDEX idx_outcome_gov ON enterprise_outcome(governance_tenant_id);
CREATE INDEX idx_outcome_action ON enterprise_outcome(action_id);
CREATE INDEX idx_outcome_status ON enterprise_outcome(status);
CREATE INDEX idx_outcome_impact ON enterprise_outcome(impact_type);
```
