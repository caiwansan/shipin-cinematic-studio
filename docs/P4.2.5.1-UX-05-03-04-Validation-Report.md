## Part A: Intelligence Loop Validation

### 验证模型

```
Backend Truth → Envelope → Store → UI → User Action → Backend Mutation
```

### 1. Source 正确性

| 数据 | Backend Source | Envelope Source | 匹配 |
|------|---------------|-----------------|------|
| Events | dashboard.businessMetrics | OperationEvent | ✅ |
| Decisions | decisions/top | DecisionEngine | ✅ |
| Actions | actions/history | ActionLifecycle | ✅ |
| Outcome | outcomes/latest | OutcomeIntelligence | ✅ |
| Signal | signals | OperationEvent | ✅ |
| Channel | channels/accounts | ChannelSync | ✅ |
| Evidence | decisions/:id/evidence | EvidenceGraph | ✅ |

### 2. Timestamp 保留

| 层级 | 实现 | 状态 |
|------|------|------|
| Backend | createdAt / updatedAt ISO | ✅ |
| Service | fetchEnvelope 包装 `freshness: new Date().toISOString()` | ✅ |
| Store | 透传 envelope.freshness | ✅ |
| UI | MetricCard / ActionCard 展示 formattedFreshness | ✅ |

### 3. Confidence 来源

| 数据 | Confidence 来源 | 状态 |
|------|----------------|------|
| Decision | Backend (decisionService) | ✅ |
| Metric | Backend (dashboard) | ✅ |
| Action | 无 (Action 不需要 Confidence) | N/A |
| Outcome | Backend (outcomeService) | ✅ |

**规则: Confidence 必须来自 Backend，Frontend 不生成。** ✅ 通过

### 4. Mutation 回写

| 操作 | Frontend Action | Backend API | 后端处理 | 状态 |
|------|----------------|-------------|---------|------|
| Accept Decision | store.acceptDecision() | POST /decisions/:id/accept | 更新 decision status | ✅ |
| Reject Decision | store.rejectDecision() | POST /decisions/:id/reject | 更新 decision status | ✅ |
| Approve Action | store.approveAction() | POST /actions/:id/approve | 更新 action status | ✅ |
| Reject Action | store.rejectAction() | POST /actions/:id/reject | 更新 action status | ✅ |
| View Evidence | store.loadEvidence() | GET /decisions/:id/evidence | 读证据图 | ✅ |

### 5. Trace 追踪

```
Action Trigger: Decision.accept() → POST /decisions/:id/accept
  → Backend: actionLifecycleService.createActionsFromDecision()
  → Frontend: store.loadDecisions() → 刷新 Decision Queue
  
Action Execution: Action.approve() → POST /actions/:id/approve
  → Backend: 更新 action.status = 'approved'
  → Frontend: store.loadAll() → 刷新 Execution Timeline
```

**Trace 链完整:** ✅
