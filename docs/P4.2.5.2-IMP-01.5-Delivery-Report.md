## Pipeline (Post IMP-01.5)

```
WeCom Event
    ↓
Crypto Verify + CallbackRuntime
    ↓
Event Normalize → Canonical Type (MESSAGE/MEDIA/VOICE/...)
    ↓
Interaction Ingest → traceId stored
    ↓
External Identity Resolve → CustomerIdentity link
    ↓
Customer Identity → pending → mapped
    ↓
customerIdentityId link on interaction
    ↓
Interaction Feed (Timeline / Query / Stats)
    ↓
Enterprise Intelligence (Signal → Decision → Action)
```
