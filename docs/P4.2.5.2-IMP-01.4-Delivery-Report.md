## 架构总览

### Identity Resolution Pipeline

```
WeCom external_userid
     ↓
 CustomerIdentityService.resolve()
     ↓
┌─────────────────────────────────┐
│ 1. Lookup (tenantId+channel+id) │
│ 2. Found? → Update stats        │
│ 3. New? → Create pending        │
│ 4. Return canonical identity    │
└─────────────────────────────────┘
     ↓
 Link interaction.customerIdentityId
     ↓
 CustomerIdentity (mapped/pending)
```

### Interaction → CustomerIdentity Link

```
CallbackEventService.processEvent()
     ↓
 interactionSyncService.ingestInteraction() → interaction
     ↓
 customerIdentityService.resolve(extId) → identity
     ↓
 UPDATE interaction SET customerIdentityId = identity.id
```

### Mapping Status State Machine

```
UNKNOWN → (auto-create on event) → PENDING
PENDING → (manual assign / auto-resolve) → MAPPED
MAPPED  → (re-sync) → MAPPED (updated)
```
