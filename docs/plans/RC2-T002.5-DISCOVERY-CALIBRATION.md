# RC2-T002.5 — Discovery Calibration & Golden Dataset

**Priority:** P0 (Blocker before RC2-T003)
**Status:** ⬜ 待执行
**Owner:** OpenClaw

---

## Objective

Calibrate the DeepSeek Discovery Provider against a curated Golden Dataset before enabling it as the default Discovery Provider. Do not modify business logic. Do not redesign Provider Infrastructure. Only improve discovery quality through calibration.

---

Create a versioned Golden Dataset at:


---

## Phase 2 — Benchmark Framework

Automated benchmark runner at `scripts/benchmark-discovery.sh`.

For every sample collect:
- Discovery result
- JSON validity
- Schema validation pass/fail
- Retry count
- Latency (ms)
- Token usage (input/output)
- Estimated cost (¥)

Generate benchmark report: `docs/reviews/DISCOVERY-BENCHMARK-REPORT.md`

Format: Markdown table with per-sample + aggregate summary.

---

## Phase 3 — Prompt Calibration

Calibrate only through:
- `prompts/discovery/system.md`
- `prompts/discovery/templates.ts`
- `prompts/discovery/schema.json`
- `prompts/discovery/parser.ts`
- `prompts/discovery/validator.ts`

Do **not** change business services. Every prompt revision must be benchmarked against the Golden Dataset.

---

## Phase 4 — Quality Gates

Measure at minimum:
- JSON validation success rate ≥ 99%
- Schema validation success rate ≥ 99%
- Scenario identification accuracy ≥ 80%
- Entity extraction accuracy ≥ 75%
- Coverage deviation ≤ ±15%
- Retry rate ≤ 5%
- Average latency ≤ 10s
- Estimated cost ≤ ¥0.001 per call

Produce comparison reports between prompt versions.

---

## Phase 5 — Shadow Calibration

Run Shadow Mode with `GEO_SHADOW_MODE=true`.

Compare: Mock vs DeepSeek vs Golden Dataset
- Accuracy differences
- Coverage differences
- False positives
- False negatives

Persist comparison history in structured JSON.

---

## Phase 6 — Provider Promotion Gate

DeepSeek may become the default Discovery Provider only after passing:

### Promotion Checklist
- [ ] Stable benchmark performance (3 consecutive runs)
- [ ] JSON validity ≥ 99%
- [ ] Schema validation ≥ 99%
- [ ] Average latency ≤ 10s
- [ ] Retry rate ≤ 5%
- [ ] No critical regressions vs previous versions
- [ ] Shadow validation: ≥ 48h without incident

Until then: Default Provider = Mock. DeepSeek remains selectable by configuration (`GEO_AI_PROVIDER=deepseek`).

## Discovery Replay (Bonus)

Each real user Discovery (anonymized) can be reviewed for inclusion in the Golden Dataset.

**Flow:**
```
Production Discovery → Anonymization → Replay Dataset → Golden Dataset Review → Benchmark → Prompt Calibration
```

Long-term, the Golden Dataset becomes a core GEO asset — enabling objective model comparison across DeepSeek, Qwen, Doubao, Gemini, etc.
