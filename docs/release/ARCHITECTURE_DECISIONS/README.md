# Architecture Decision Records (ADR)

**用途**: 记录重要的架构决策，确保技术选择有据可查

---

## 模板

### ADR-XXX: [决策标题]

**日期**: YYYY-MM-DD  
**状态**: Proposed / Accepted / Superseded  
**决策者**: [姓名/团队]

#### 背景
[为什么要做这个决策？有什么约束？]

#### 决策
[我们决定了什么？]

#### 理由
[为什么这样选？考虑了哪些替代方案？]

#### 影响
- 正面：[收益]
- 负面：[代价]
- 风险：[可能的问题]

#### 参考
- [相关 PRD]
- [相关技术文档]
