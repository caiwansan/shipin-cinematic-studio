## 2. Section → User Question 映射

| Section | CEO 问题 | 数据来源 | Envelope 字段 |
|---------|---------|---------|--------------|
| Today Intelligence | 现在发生什么？ | OperationEvent | value + source + freshness |
| Decision Queue | 我要决定什么？ | DecisionEngine | title + rationale + confidence |
| Execution Timeline | 系统在做什么？ | ActionLifecycle | name + stage + progress |
| Channel Health | 渠道正常吗？ | ChannelSync | name + connected + lastSync |
| Outcome Snapshot | 结果如何？ | OutcomeIntelligence | status + impact + verifiedAt |

## 3. 四条 CEO 使用路径

### Path 1 — Morning Brief（早间简报）

```
CEO 登录
  → Today Intelligence: "今日 3 个事件需要关注"
  → 发现异常信号
  → 进入 Decision Queue
  → Review Evidence
  → Approve Decision
```

**关键交互:**
- MetricCard 展示数字+来源+新鲜度
- Urgent Badge 提示优先级
- 1-click Refresh 获取最新数据

### Path 2 — Decision Review（决策审查）

```
Decision Queue
  → 查看 Pending Decision
  → View Evidence
  → EvidenceGraph 展示依据链
  → Approve / Reject
  → Action 自动生成（后续 UX-04 已完成）
```

**关键交互:**
- DecisionCard 展示 Title + Reason + Impact + Confidence
- Evidence Panel 展示 Source/Relationship/Confidence
- Approve/Reject 双操作

### Path 3 — Execution Monitoring（执行监控）

```
Execution Timeline
  → Pending Approval: "2 个 Action 等待审批"
  → 查看 ActionCard（Trigger + Stage + Progress + Owner）
  → Approve Action
  → Running 区展示实时进度
  → 完成后链接到 Outcome
```

**关键交互:**
- ActionCard 展示生命周期状态
- Progress Bar 可视化进度
- Source/Freshness 保证数据可信

### Path 4 — Business Learning（业务学习）

```
Outcome Snapshot
  → 查看上次 Action 结果
  → Verified Status 确认闭环
  → 分析影响
  → 下一轮 Intelligence 开始
```

**关键交互:**
- Outcome 展示 Status + Title
- Verified Badge 确认完成
- 时间线理解因果链

## 5. Data Trust 验证（Gate 3）

### 所有展示数据必须包含

```typescript
// 正确展示
{
  value: 8,
  source: "ActionLifecycle",
  freshness: "2 min ago",
  confidence: 0.92
}

// 禁止展示
{
  value: 8  // 无 Source, 无 Freshness
}
```

### 现有组件合规检查

| 组件 | Value | Source | Freshness | Confidence | 状态 |
|------|-------|--------|-----------|------------|------|
| MetricCard | ✅ | ✅ | ✅ | ✅ | PASS |
| DecisionCard | ✅ | ✅ | ✅ | ✅ | PASS |
| ActionCard | ✅ | ✅ | ✅ | ❌ | PASS (Action 无 Confidence) |
| StatusBadge | ✅ | — | — | — | PASS (Badge 不需要) |

## 6. Empty State 验证（Gate 4）

### 新租户场景

**所有 Section 均为空时，CEO 看到:**

```
Section 1: "当前暂无智能事件。系统正在等待数据接入。"
Section 2: "暂无待决策事项。AI 团队正在监控中。"
Section 3: "暂无执行中行动。已通过审批的决策将在此展示。"
Section 4: "未连接渠道。连接企业渠道以查看状态。"
Section 5: "暂无结果。行动完成并验证后将在此展示。"
```

**禁止出现:**
- ❌ 空白页 (Blank Page)
- ❌ `undefined`
- ❌ `No Data`（无引导下一步）
- ❌ 裸数字无来源

## 7. 验证结果

### Gate 1: First 30 Seconds — ✅ PASS

1. ✅ 企业现在状态 → Today Intelligence (4 MetricCards)

```
Signal (OperationEvent) ✅
  → Understand (Dashboard Intelligence) ✅
    → Recommendation (DecisionEngine) ✅
      → Decision (Decision Queue) ✅
        → Evidence (EvidenceGraph) ✅
          → Approve (Accept API) ✅
            → Action (ActionLifecycle) ✅
              → Execution (Timeline) ✅
                → Outcome (Verified) ✅
```

### Gate 3: Data Trust — ✅ PASS

所有数字均包含 Value + Source + Freshness。
MetricCard 和 DecisionCard 完整展示 Confidence。

### Gate 4: Empty Production State — ✅ PASS

所有 5 个 Section 均配置 EmptyState 组件，包含引导文本和下一步动作。
