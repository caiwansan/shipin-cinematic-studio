# 昆仑镜 · AI 全渠道运营中心 Design System v1

**Sprint:** MEDIA-UX-PRODUCT-DESIGN-05（设计语言冻结）
**Date:** 2026-08-02
**Gate:** 掌柜战略纠偏（UX-04 把「深紫切白灰」是去风险设计不是高级设计；根本问题 = 产品设计语言没有建立 → 先冻结 Design System，再统一重做 8 页面，禁止继续局部补丁）

## 0. 设计哲学（掌柜原话，长期遵守）

- 世界级 SaaS UI ≠ 深色科技风；≠ 白色后台风；= **品牌气质 + 空间层次 + 视觉记忆 + 高级克制易用**
- 昆仑镜定位：**「AI 时代企业经营操作系统」**——未来感 + 商业感 + 智能感
- 参考但不照抄：Apple 克制感 / Notion 信息组织 / Linear 现代效率 / Stripe 商业质感
- AI 是助手，不是展示品；老板无需学习即可理解

## 1. 颜色体系（90% 中性 / 7% 蓝青 / 3% 紫）

| 角色 | 色值 | 用途 |
|------|------|------|
| 主背景 | `#F4F6FA` | 未来企业办公空间（非纯白非纯黑） |
| 卡片 | `#FFFFFF` | 所有卡片 |
| 边框 | `#E5E7EB` | 卡片/分割细线 |
| 主文字 | `#111827` | 标题/数字 |
| 辅助文字 | `#64748B` | 正文 |
| 弱文字 | `#9CA3AF` | 说明/时间戳 |
| **昆仑蓝** | `#2563EB` | CTA / 激活态 / AI 标识 / 链接（品牌主色） |
| **青蓝** | `#06B6D4` | 数据流 / AI 状态点 / 智能点缀 |
| **成长绿** | `#10B981` | 增长 / 成功 / 运行中 |
| **少量紫** | `#8B5CF6` | 仅 AI 能力标签 / 特殊状态（≤3%） |
| 预警 | `#D97706` | 需要留意 |
| 下降 | `#DC2626` | 负向 |

禁止：大面积渐变、深紫科技模板、金色、荧光绿（深色主题色禁止进入白天界面）。

## 2. 字体层级

| 层级 | 字号/字重 | 用途 |
|------|----------|------|
| 页面标题 | 24px / 800 | 页面头 h1 |
| 区块标题 | 14-15px / 800 | 区块头（经营状态/AI已完成…） |
| 卡片标题 | 12.5-13px / 800 | 卡内标题 |
| 正文 | 12-13px / 500-600 | 描述 |
| 弱说明 | 10.5-11px / 600 | 时间戳/辅助 |
| 大数字 | 24-28px / 900 | KPI 数字（克制，不超大） |
| 中数字 | 16-18px / 800 | 次级数字 |

字体系：系统字体栈 + `--font-mono` 用于编号/代码感点缀。

## 3. 空间与卡片规范

- 间距体系：4 / 8 / 10 / 12 / 16 / 20 / 24（SaaS 紧凑节奏）
- 页面边距：32px 左右（≤1320 容器）
- **信息卡高度 80-120px**（禁止 300px 大卡/儿童 App 风）
- 卡片：白底 + 1px #E5E7EB 边框 + `0 1px 2px rgba(16,24,40,0.04)` 微投影
- 卡内 padding：12-16px；卡间 gap：10-12px
- 信息密度：比常规后台高 40%，一行内同时呈现「标题+数字+趋势+来源」

## 4. 图标体系

- 风格：**单色线性（stroke 1.5，16px）**，SVG 优先；不用 emoji 不用彩色图标
- 导航图标：线性符号（⌂ ♙ ✎ ♡ □ ◫ ◌ 等，或 SVG）
- 状态点：5-7px 圆形实心点，仅 3 色（绿=运行/增长，青蓝=AI 状态，灰=待接入）

## 5. 状态体系

| 状态 | 样式 |
|------|------|
| 运行中/增长 | 绿点 + 绿字（#10B981） |
| AI 智能 | 青蓝点（#06B6D4） |
| 待接入/已就位 | 灰点 + 灰字（#9CA3AF/#64748B） |
| 需要留意 | 琥珀（#D97706） |
| 下降/失败 | 红（#DC2626） |

状态表达统一为「点 + 文字」，禁止大徽章/大发光。

## 6. 数据展示规范

- 数字大但克制（≤28px），千分位/万单位人性化（12.8万 / ¥68,900）
- 每个数字必须带：单位或趋势（↑↓%）+ 来源/周期说明
- 无数据一律「待接入」，禁止 0 / -- 造假
- AI 判断/建议用一行「💡 AI：…」或「AI判断：…」表述，跟随数据（无数据不生成）
- 趋势三态：↑绿 / ↓红 / →灰

## 7. 页面结构（8 页面统一）

- 所有页面 = `MediaWorkspaceShell` + `MediaPageHeader`（kicker/标题/状态/描述）
- 区块头统一：左侧标题 + 右侧操作/说明
- 首页 = 老板桌面（见 index 规范）：
  1. 问候条：「早上好，老板」+ 日期 + AI 团队状态
  2. 经营状态：健康指数 / 收入趋势 / 客户增长 三卡（紧凑）
  3. 今天 AI 已完成：✓ 清单（真实数据，空态说明）
  4. 本周经营表现：苹果式摘要（↑12% 大数字 + 三指标 + AI 判断）
  5. 我的业务地图：内容 / 客户 / 商品 / 渠道 四入口
- 团队页 = 「我的 AI 管理层」组织式列表（不是卡片墙）
- 数据页 = 摘要式（不做 270° 仪表盘/驾驶舱罗盘）

## 9. 实现机制

- **Design Tokens v4.0**（media-tokens.css）：--media-* 全量定义
- **作用域覆盖**：Shell `.mws` 上覆盖 --color-*（白天值）→ 子页 140+ 处深色 enterprise 变量引用在媒体工作区内自动白天化，且不影响短剧/招聘/企业工作台（作用域隔离）
- 禁止：页面内硬编码深色 hex/rgba；新 API/新表/新页面/新功能（纯视觉收敛）
