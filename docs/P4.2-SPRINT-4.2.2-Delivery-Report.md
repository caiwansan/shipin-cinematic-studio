## 核心能力交付

### Priority Score Engine（冻结公式）

```
Score = Impact × Urgency × Confidence / 100

Impact:   critical=10 / warning=6 / info=3
Urgency:  events>5=8 / >2=5 / else=2
Confidence: Evidence Quality Score (0-100)
           无证据=20 / 单一事件=45 / 多事件=70 / 多源=90 / 完整=100

Level: P1(≥70) / P2(40-69) / P3(20-39) / P4(<20)
```

### Decision Ranking

```
排序: Priority Score DESC → Urgency DESC → CreatedAt ASC
默认: Top 3
最大: Top 20
```

### Evidence Graph

```
Recommendation (Layer 1)
    → Signal (Layer 2)
        → OperationEvent (Layer 3, max 17 nodes)

总节点 ≤ 20, 深度 ≤ 3
Node 包含: id, type, description, timestamp, confidence, metadata
```

### Decision Status Lifecycle

```
Detected → Reviewed → Accepted → (Action Lifecycle)
                     → Dismissed
                     → Expired (信号生命周期结束)
```
