## 三、替代关系 — 旧代码 → 新组件

| 旧代码位置 | 模式 | 新组件 | 说明 |
|-----------|------|--------|------|
| enterprise/index.vue 第 30-60 行 | 硬编码 KPI div | MetricCard | 用 v-for + MetricCard 替代 |
| enterprise/index.vue 第 80-120 行 | 内联 Channel Status | StatusBadge + ChannelHealth | 统一状态显示 |
| enterprise/index.vue 第 150-200 行 | 内联 Decision List | DecisionCard | 统一决策展示 |
| default.vue | 整个布局 | EnterpriseShell | 替换整个 Layout |
| leads.vue `<table>` | 原生 table | EnterpriseTable | 统一表格样式 |
| tasks.vue 列表 | 裸 ul/li | Timeline + ActionCard | 升级时间线 |
| 全站 | `style="color: #xxx"` | enterprise-tokens.css | CSS 变量统一 |
| 全站 | 无 loading | Skeleton | 骨架屏 |
| 全站 | "No data" 文字 | EmptyState | 空状态统一 |

## 四、禁止清单 — 页面永远不能做的事

| ❌ 禁止 | ✅ 必须 |
|---------|---------|
| `<div class="card">` 手写样式 | 使用 EnterpriseCard / MetricCard / DecisionCard |
| `color: #8B5CF6` 硬编码 | `color: var(--color-intelligence)` |
| `fetch('/api/...')` 在页面内 | 通过 Store → Service → API |
| `const signals = Math.random()` | API 返回 → Store → Component |
| `<button class="btn">` 裸按钮 | `<Button variant="primary">` |
| `v-if="loading"` 后无内容 | `<Skeleton v-if="loading" />` |
| `v-if="data.length === 0"` 显示 "No data" | `<EmptyState title="No Data" />` |
| 任何 emoji 作为图标 | SVG Icon 组件 |
| 任何表格直接用 `<table>` | EnterpriseTable 组件 |
| 任何硬编码的企业名称 | 从 useEnterpriseContext 获取 |

## 六、验收标准

### 通过条件

1. ✅ 文件树冻结后，所有新页面 /components/enterprise-ui/ 下开发
2. ✅ 旧代码不得新增（只能被新组件替代）
3. ✅ 所有颜色引用 CSS 变量
4. ✅ 所有异步加载使用 Skeleton
5. ✅ 所有空数据使用 EmptyState
6. ✅ 页面禁止自己造 Card/Table/Button

### 不通过条件

- ❌ 任何页面内存在内联 `style="color: #xxx"`
- ❌ 任何页面直接使用 `<table>`
- ❌ 任何页面手写 Card `<div class="card">`
- ❌ 任何数字来自 Math.random() 或硬编码
