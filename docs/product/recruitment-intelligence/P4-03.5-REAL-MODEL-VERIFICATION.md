## 2. 测试用例

### Case 1：高级前端工程师

**JD 文本：**

```
职位：高级前端工程师

岗位职责：
1. 负责企业级 Web 应用前端架构设计和开发；
2. 参与前端工程体系建设，提升应用性能和用户体验；
3. 与后端、产品、设计团队协作完成业务交付。

任职要求：
1. 5年以上前端开发经验；
2. 熟练掌握 Vue3、TypeScript、JavaScript；
3. 熟悉 Nuxt、React、Webpack 等前端工程化工具；
4. 有大型 SaaS 或企业应用开发经验；
5. 具备良好的代码规范意识和系统设计能力。
```

**预期输出：**

```json
{
  "requiredSkills": ["Vue3", "TypeScript", "JavaScript"],
  "preferredSkills": ["Nuxt", "React", "Webpack"],
  "experienceMin": 5,
  "jobLevel": "Senior",
  "indicators": ["5年以上", "熟练掌握", "企业级"]
}
```

**验证规则：**
- ✅ `requiredSkills` 必须包含 Vue3、TypeScript、JavaScript（3/3）
- ✅ `preferredSkills` 至少包含 Nuxt、React、Webpack 中 2 个
- ✅ `experienceMin` 必须 = 5
- ✅ 不应出现 JD 中不存在的技能（如 Python、Go）

## 3. Validation Rules（通用）

| 规则 | 说明 | 严重度 |
|------|------|--------|
| 技能覆盖率 | `requiredSkills` 命中率 ≥ 80%（与预期交集/预期总数） | ERROR |
| 幻觉检测 | `requiredSkills` 中出现 JD 中完全不存在的技能 | ERROR |
| 年限准确性 | `experienceMin` 必须与 JD 中明确数字一致 | ERROR |
| 技能标准化 | 技能名必须匹配 `Skill` 表 canonical name 或 alias | WARNING |
| 经验范围 | 若 JD 给出范围（如 3-5 年），`experienceMin` ≤ 实际 ≤ `experienceMax` | WARNING |
| 学历合理性 | 不应从无关上下文推断学历 | INFO |

## 4. 执行流程

```
Step 1: 掌柜/管理员在 Model Router 中配置真实 LLM Key
         ↓
Step 2: 运行 `scripts/p4-real-model-verification.ts`
         ↓
Step 3: 脚本调用 POST /api/job/match/requirements/extract
         ↓
Step 4: 对比实际输出 vs 预期结构
         ↓
Step 5: 生成 Diff Report（PASS / WARN / FAIL）
         ↓
Step 6: 全部 PASS → P4-03 Production Ready ✅
         有 FAIL → 分析原因 → 修复 Prompt/Validator → 重跑
```
