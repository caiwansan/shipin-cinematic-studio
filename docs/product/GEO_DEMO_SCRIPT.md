# GEO 产品演示脚本 v1.0

**依据**：《昆仑镜 GEO 产品白皮书 v1.0》第四章（八阶段工作流）
**用途**：每次发版前按此脚本完整走一遍，任何一步不可用则禁止发布。

---

## 前置条件

- PM2 进程 43（nuxt-frontend）和 41（api-server-aigc）均为 online
- 浏览器打开 `https://aigc.fushtn.com/workspace/geo`

---

## Step 1：品牌创建（Build）

| 操作 | 预期结果 |
|------|---------|
| 打开 GEO 工作台 | 左侧面板显示项目列表，初次使用显示空态引导 |
| 创建新品牌 | 品牌出现在左侧项目列表中，可选中 |
| 选中品牌 | 中间 Tab 加载该品牌数据 |

**阻断条件**：项目列表为空且无"创建"入口，或创建后无法选中。

---

## Step 2：AI 收录检测（Analyze）

| 操作 | 预期结果 |
|------|---------|
| 切换到 Overview Tab | 显示 GEO 评分（数字） |
| 评分可见 | 五维评分至少有一维有数据 |
| 评分含义 | 数字附带有文字说明（非原始数值） |

**阻断条件**：评分无法显示或报错。

---

## Step 3：质量报告（Report）

| 操作 | 预期结果 |
|------|---------|
| Overview Tab 查看报告 | 显示 GEO 评分 + 发布健康度图表 + 趋势说明 |
| 评分明细 | 每个维度有 ExplainPanel 说明原因 |

**阻断条件**：评分无原因说明或显示原始数据无解释。

---

## Step 4：优化建议（Optimize）

| 操作 | 预期结果 |
|------|---------|
| 切换到 Insights Tab | 显示优化建议列表 |
| 建议内容 | 每条建议包含标题 + 原因 + 置信度标记 |
| 右侧 Panel | 右侧 InsightsPanel 同时显示建议列表 |

**阻断条件**：建议列表为空（只有空态文案时接受"暂无优化建议"）。

---

## Step 5：执行优化（Execute）

| 操作 | 预期结果 |
|------|---------|
| Insights Tab 点击"应用优化" | 按钮变为"提交中..."，不可重复点击 |
| 提交后 | 显示"任务已提交"反馈（绿色） |
| InsightsPanel 点击"应用优化" | 同样触发验证 |
| Evidence Tab 点击"重新验证" | 验证触发，完成后列表更新 |
| Timeline Tab 点击"重新执行" | 验证触发，时间线更新 |

**阻断条件**：按钮无反馈或 API 返回错误。

---

## Step 6：发布（Publish）

| 操作 | 预期结果 |
|------|---------|
| 切换到 Publish Tab | 显示发布记录列表 |
| 发布记录 | 每项有状态标记（已发布/待审阅/已回滚） |
| 内容对比 | 有 before/after 对比显示 |

**阻断条件**：发布列表报错。

---

## Step 7：验证（Verify）

| 操作 | 预期结果 |
|------|---------|
| Evidence Tab | 显示验证记录列表 |
| 验证条目 | 每条显示 Delta 变化 + 是否改善标记 |
| 可追溯 | 点击条目可查看详情（可选） |

**阻断条件**：验证记录报错或无法显示。

---

## Step 8：持续监测（Monitor）

| 操作 | 预期结果 |
|------|---------|
| Overview Tab | 活跃任务数量显示 |
| 右侧 InsightsPanel | 活跃告警角标显示 |
| 品牌名称右侧 | 项目列表显示品牌状态标记（可选） |

**阻断条件**：所有监测数据均为空且无告警标记。

---

## 全流程串联

```text
打开 /workspace/geo
  → 左侧：选择项目（或创建）
  → Overview：查看评分
  → Insights：查看建议
  → 点击"应用优化"
  → 等待完成
  → Evidence：查看验证结果
  → Timeline：查看事件
  → Publish：查看发布
  → Insights：查看新建议
```

**阻断条件**：以上路径中任一步骤因 UI 缺失/API 错误/空态崩溃而无法继续。

---

## 发版门禁

以上任一步骤出现以下问题的，禁止发布：

1. **白屏/崩溃**：Vue 渲染错误导致整个页面不可用
2. **API 500**：后端返回 Internal Server Error
3. **死循环 loading**：组件无限 loading 不显示数据
4. **操作无反馈**：按钮点击后没有任何状态变化
5. **数据不一致**：两个 Tab 显示同一项目的数据冲突
