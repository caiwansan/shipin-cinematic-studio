## 左侧 Panel：Projects

| 项 | 内容 |
|---|---|
| 页面目的 | 用户进入 GEO 后看到的第一个界面，回答"我有哪个品牌" |
| 用户操作 | 点击品牌切换 → 选中品牌 → 中间 Tab 加载该品牌数据 |
| 用户操作 | 点击"新建项目" → 输入品牌名称/网址 → 创建品牌档案 |
| 用户操作 | 查看品牌状态标识（评分/收录状态/告警数） |
| 数据加载 | `GET /api/geo/projects` |
| 输出结果 | 品牌列表，每个显示名称 + 评分 + 状态标记 |

---

## 中间 Tab：Overview

| 项 | 内容 |
|---|---|
| 页面目的 | 用户来到这里以后必须回答：**我的品牌现在怎么样？** |
| 用户操作 | 查看 GEO 评分（总评分 + 五维评分） |
| 用户操作 | 查看发布时间分布、收录状态 |
| 用户操作 | 点击"开始检测" → 触发 AI 收录检测 |
| 用户操作 | 点击"查看报告" → 跳转到完整质量报告 |
| 数据加载 | `GET /api/geo/recommendation/score?projectId=` (GEO 评分) |
| 数据加载 | `GET /api/geo/monitor/dashboard/:projectId` (发布数量/活跃告警) |
| 数据加载 | `GET /api/geo/reports/generate?projectId=&type=` (完整报告) |
| 输出结果 | 用户对品牌健康状况一目了然 |
| 白皮书章节 | 第二阶段（Analyze）+ 第三阶段（Report） |

**当前状态**：✅ 评分和仪表盘数据正常显示。报告页面需增强。

## 中间 Tab：Timeline

| 项 | 内容 |
|---|---|
| 页面目的 | 用户来到这里以后必须回答：**最近发生了什么？** |
| 用户操作 | 按时间顺序查看所有事件（优化→验证→发布→观测→收录→漂移→学习） |
| 用户操作 | 点击"重新执行" → 触发验证，系统重新执行后更新时间线 |
| 数据加载 | `GET /api/geo/verification/timeline/:projectId` |
| 输出结果 | 用户了解品牌运营的历史轨迹 |
| 白皮书章节 | 第七阶段（Verify） |

**当前状态**：✅ 时间线显示正常，"重新执行"按钮可用。

---

## 中间 Tab：Evidence

| 项 | 内容 |
|---|---|
| 页面目的 | 用户来到这里以后必须回答：**为什么得到这个评分？** |
| 用户操作 | 查看每次验证的 Delta 变化 |
| 用户操作 | 查看哪些维度改善/下降 |
| 用户操作 | 点击"重新验证" → 触发全量验证 |
| 数据加载 | `GET /api/geo/verification/history/:projectId` |
| 输出结果 | 用户理解评分变化的根因 |
| 白皮书章节 | 第七阶段（Verify） |

**当前状态**：✅ 验证历史列表正常显示，"重新验证"按钮可用。
