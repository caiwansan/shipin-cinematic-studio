## 一、问题定义

Sprint 4.2.1 已建立 Signal Feed 能力:
> CEO 能看到发生了什么 (Events) → 什么值得注意 (Signals) → 建议行动 (Recommendations)

## 二、四大核心能力

### 2.1 Prioritization Engine（优先级引擎）

**公式**:

```
Priority Score = Impact × Urgency × Confidence
```

**因子定义**:

| 因子 | 来源 | 范围 |
|------|------|------|
| Impact | 信号严重度 + 影响范围 | 1-10 |
| Urgency | 时间窗口（如商机超时） | 1-10 |
| Confidence | 证据链完整度 | 0-100% |

**计算规则**（冻结前需 CTO 批准）:

```typescript
// Priority Score Formula v1.0 (待冻结)
function calculatePriority(signal: Signal, evidence: Evidence[]): PriorityScore {
  const impact = signal.severity === 'critical' ? 10 : 
                 signal.severity === 'warning' ? 6 : 3
  
  const urgency = signal.sourceEvents.length > 5 ? 8 :
                  signal.sourceEvents.length > 2 ? 5 : 2
  
  const confidence = Math.min(100, evidence.length * 25 + 25)  // evidence=0→25%, 1→50%, 2→75%, 3+→100%
  
  return {
    score: Math.round((impact * urgency * confidence) / 100),
    impact,
    urgency,
    confidence,
  }
}
```

**优先级分档**:

| Score | 级别 | CEO 感知 |
|-------|------|----------|
| ≥70 | P1 | 立即处理 |
| 40-69 | P2 | 今天处理 |
| 20-39 | P3 | 本周处理 |
| <20 | P4 | 持续关注 |

### 2.3 Evidence Graph（证据图）

**目标**: 形成「可审计决策链」

```
Recommendation
    ↓
Signal (why this matters)
    ↓
OperationEvent (what happened)
    ↓
Database Record (source truth)
```

**数据结构**（MVP 轻量版）:

```typescript
interface EvidenceNode {
  id: string
  type: 'signal' | 'event' | 'lead' | 'content' | 'interaction'
  description: string
  timestamp: Date
  metadata: Record<string, any>
}

interface EvidenceGraph {
  recommendationId: string
  nodes: EvidenceNode[]
  connections: { from: string; to: string; reason: string }[]
}
```

**前端展示**: CEO 点击建议标题 → 展开 Evidence Graph → 可追溯到原始事件

---

### 2.4 Decision Status（决策状态扩展）

**明确区分**:

- **Decision** = 系统判断（Detected → Reviewed → Accepted）
- **Action** = 执行（Pending → Approved → Executed → Verified）

**状态机**:

```
Detected (系统自动检测)
    ↓
Reviewed (CEO 查看，进入 Top 3)
    ↓
Accepted (CEO 认可，触发 Action)
    ↓
↓ 转入 Action Lifecycle
Pending (等待执行)
    ↓
Approved (人工审批)
    ↓
Executed (Agent/人工执行)
    ↓
Verified (效果确认)
```

## 七、Entry Gate — 冻结三个 Contract

### Contract 1: Priority Score Formula v1.0

```
Score = Impact × Urgency × Confidence / 100
Impact = severity(critical:10, warning:6, info:3)
Urgency = sourceEvents(>5:8, >2:5, else:2)
Confidence = min(100, evidenceCount * 25 + 25)
```

### Contract 2: Decision Ranking Contract

- Top N = 3（CEO 只看到 Top 3）
- 排序: Priority Score DESC → Urgency DESC → CreatedAt ASC
- 每天重新计算一次（或信号变化时）

### Contract 3: Evidence Graph Contract

- Evidence Node 类型: signal / event / lead / content / interaction
- 最大深度: 3 层（Recommendation → Signal → Event）
- 存储: JSONB 内嵌（不建独立表）
