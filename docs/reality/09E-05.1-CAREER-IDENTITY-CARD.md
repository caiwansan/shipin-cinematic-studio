## 核心架构

```
User DB (CareerProfile / WorkExperience / CandidateSkill / Education)
  ↓
buildCareerAgentContext(userId)  ← 统一 Context Authority
  ↓
CareerAgentContext {
  identityCard: {         ← 只读，Confirmed Facts Only
    identity: { name, location },
    career: { currentRole, experienceYears, industries },
    skills: [],
    education: [],
    workHistory: [],
    confirmedFacts: [],
    careerGoals: []
  },
  currentContext: {       ← 动态，随用户行为变化
    currentGoal,
    missingInformation
  },
  activeActions: [],      ← Career Action 进行中任务
  recentFeedback: []      ← 最近 3 条反馈
}
  ↓
Chat       → systemPrompt 注入 identity card
Planning   → 基于 identity card 映射
Actions    → 继承 planning 上下文
Matching   → 可读取 identity card
Talent Mkt → CandidateCard (由 syncToCareerProfile 触发 upsert)
```

## 故障模式

| 场景 | 行为 |
|------|------|
| 无 CareerProfile | buildCareerAgentContext 抛错 → orchestrator 静默捕获 → 无身份卡，正常对话 |
| legacy_unknown | 数据门控抛出 → 不进入身份卡 → free tier 照常 |
| review_required | 数据门控抛出 → 不进入身份卡 |
| 新用户（空会话） | 创建新 ConversationState，不注入身份卡 → 从 GREETING 开始采集 |
