# Sprint-MEDIA-UX-CONSOLIDATION-04 — 昆仑镜统一 Workspace · UX 收敛治理 — COMPLETE ✅

**Date:** 2026-08-02 06:50 CST
**Gate:** 掌柜战略指令（前面 Sprint 把产品逻辑做对了，现在暴露更深层的 Design System 问题：新媒体工作台正在变成「堆功能的 AI 后台」，还没有形成昆仑镜统一 Workspace 的高级感 → 停止加模块，进入 UX 收敛治理）

## 定位转变
功能堆叠后台 / 大卡片数据展示页 / 紫色科技模板 → **昆仑镜统一 Workspace / 高级 SaaS 产品界面 / 企业经营软件**

## 一、Workspace 结构治理（入口收敛，单一入口原则）
- **模型入口 3 → 1**：删除顶部「模型设置」快捷按钮 + 用户卡「模型」按钮（WorkspaceUserCard 新增 `hideModelEntry` prop，默认 false 不影响 EnterpriseShell）；仅保留左栏底部「⚙ 模型中心」
- **返回首页 2 → 1**：删除顶部「← 昆仑镜首页」按钮；仅保留左栏底部「← 昆仑镜首页」
- **删除右上角 WorkspaceSwitcher**（工作空间选择收敛至昆仑镜首页，保证产品确定感）
- 顶栏只保留：当前模块图标 + 名称 + Live 状态徽章

## 二、颜色体系推翻（白天模式 · 90/8/2 法则）
- 旧：深墨灰背景 + 大面积昆仑紫（紫色背景/紫色卡片/紫色渐变/紫色按钮 = AI 模板网站廉价感）
- 新：**90% 中性色（#F7F8FA 背景 / #FFFFFF 卡片 / #111827 文字 / #64748B 辅助）+ 8% 蓝 + 2% 紫**
- AI 强调 **#6366F1（indigo）只做点缀**：激活态 / CTA / AI 标识 / 数字强调
- 语义色白天化：成长绿 #16A34A / 下降 #DC2626 / 预警 #D97706
- 参考：Stripe / Linear / Notion；定位：企业经营软件，不是 AI 科技

## 三、首页信息层级压缩（三层，老板不用滚很远）
- **第一层 经营状态 40%**：标题条（AI 经营总部 + 企业操作系统徽章 + AI 团队状态）+ 三列（经营健康卡 / 今日核心指标 3 行 / AI 今日简报）
- **第二层 AI 正在工作 30%**：5 张紧凑员工卡（小头像 32px + 名字/角色 + 状态徽章 + 今日完成 ✓×2 + 查看详情 →）
- **第三层 经营资产 30%**：渠道/商品/客户资产卡 + 数据同步 + 近 7 天趋势 4 小卡 + 渠道入口（底部中性）
- 页面总高 ~900px（原为超长滚动）；卡片高度降 35-45%，信息密度提高，留白减少

## 四、导航去 emoji（线性图标）
- 主导航：⌂ 经营总部 / ♙ AI员工 / ✎ 内容工厂 / ♡ 客户中心 / □ 商品经营 / ◫ 数据洞察 / ◌ 行业机会
- 底部系统入口：⚙ 模型中心 / ⇄ 渠道中心 / ★ 会员中心 / ← 昆仑镜首页

## 五、员工卡收敛（不再像招聘页）
小圆角首字母头像（indigo 浅底，无大渐变）→ 名字 + 岗位 → 状态点 → 今日完成清单 → 查看详情 >，全卡紧凑单行布局。

## 六、Design Token v3.0（media-tokens.css）
变量名全兼容（子页自动跟随白天模式，零子页改动）；深色硬编码清零（仅 Shell/index 有，已全部白天化）
