## 问题

之前 G4 验证的只是 **已有 CareerProfile 用户回访** 场景。

缺失的是：

> 新用户首次打开 Career Agent，从 0 开始建立职业身份。

## 三层断裂根因

| 层级 | 问题 | 修复 |
|------|------|------|
| L1 | Identity Card 只从 DB 加载 → cold start 的 `buildCareerAgentContext()` 抛异常 → `identityCard=undefined` → 全程空白 | 新增 `ConversationCareerState` 对话级实时身份状态 |
| L2 | System prompt 注入的 identity card 是静态的 — 只在 state 创建时从 DB 读取一次，对话过程中永不更新 | `rebuildIdentityCardFromCareerState()` 每次 mergeExtractedFields 后重建身份卡 |
| L3 | `syncToCareerProfile()` 只在阶段推进时触发 — 冷启动全程无 DB 写入 | `checkMinimumDataThreshold()` 达到最低信息阈值即创建 Draft Profile |

## 修复内容

### 文件修改

**`career-conversation-orchestrator.ts`** — 10 项精准编辑：

| 编辑 | 修改内容 |
|------|---------|
| E1 | 新增 `ConversationCareerState` interface — 对话级事实映射、已收集字段列表、实时身份卡 |
| E2 | `ConversationState` 增加 `careerState: ConversationCareerState` |
| E3 | `getOrCreateState()` 冷启动时初始化 careerState，DB 有数据时同步到 careerState |
| E4 | `restoreStateFromProfile()` 恢复时初始化 careerState |
| E5 | 新增 `rebuildIdentityCardFromCareerState()` + `updateConversationIdentityCard()` |
| E6 | `processWithAlice()` Step 1 后插入 `syncProfileToCareerState()` + `updateConversationIdentityCard()` + `checkMinimumDataThreshold()` |
| E7 | 新增 `syncProfileToCareerState()` — 同步所有字段到 careerState |
| E8 | 新增 `checkMinimumDataThreshold()` — 最低阈值自动创建 Draft CareerProfile |
| E9 | `extractInfoViaLLM()` + `generateReplyViaLLM()` 使用 conversation identityCard |
| E10 | `persistState()` 保存 careerState 到 metadata |

## 冷启动流程（修复后）

```
用户消息
  ↓
extractInfoViaLLM() → 从 LLM 提取结构化 JSON
  ↓
mergeExtractedFields() → 信任过滤 → 写入 state.profile
  ↓
syncProfileToCareerState() → 同步 state.profile → careerState
  ↓
updateConversationIdentityCard() → 重建身份卡（合并 DB + 对话数据）
  ↓
checkMinimumDataThreshold() → 达到阈值（name+role+exp）→ 创建 Draft Profile
  ↓
generateReplyViaLLM() → 注入对话身份卡 → 回复不重复询问
```

## 现实测试

### 测试用例

```
用户1: 李雷
  → collectedFields=['name'], hasMinimumData=false
  → identityCard: { name: "李雷" }
  → 下一步：了解方向

用户2: 10年软件开发
  → collectedFields=['name','yearsOfExperience'], hasMinimumData=true
  → identityCard: { name: "李雷", experience: 10 }
  → 触发 Draft CareerProfile 创建

用户3: AI智能体
  → collectedFields=['name','yearsOfExperience','targetRole'], hasMinimumData=true
  → identityCard: { name: "李雷", experience: 10, direction: "AI智能体" }
  → 更新 Draft Profile

用户4: LangChain, Python, 大模型
  → collectedFields=['name','yearsOfExperience','targetRole','skills'], hasMinimumData=true
  → identityCard: +skills: [LangChain, Python, 大模型]

用户5: 本科, 软件工程
  → collectedFields=['name','yearsOfExperience','targetRole','skills','educationLevel','major']
  → identityCard 全量：姓名+经验+方向+技能+学历+专业
```
