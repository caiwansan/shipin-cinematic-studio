2. **① 经营数据罗盘（核心大视觉）**：270° 圆形表盘（SVG 刻度 + 渐变弧 + 进度填充）→ 中心健康度 + 状态；三轴（内容影响 / 客户增长 / 销售转化，带 ↑↓ 趋势）；右侧今日经营速览三格（内容曝光 / 新增客户 / 成交金额，各带趋势）；底部**数据汇聚链**：内容 6 平台 + 电商 5 平台 + 企业微信 → AI 全渠道数据汇总 → 经营驾驶舱（让老板知道数据不是假的、来自所有渠道，但渠道不占第一层）
3. **② 今日经营总览**（六张漂亮小卡，非后台报表）：

   - 👥 粉丝资产（粉丝总量 / 今日新增）
   - 💬 客户经营（新增客户 / 咨询人数）
   - 🛒 商品销售（成交金额 / 订单）
   - 🔥 品牌热度（搜索增长 / 互动率）
   - 🤖 AI 工作成果（生成内容 / 回复客户 / 分析报告）
   - 每卡五行内：图标 + 标题 / 核心数字 / 变化趋势 / 来源说明
4. **③ AI 正在帮你经营**（不再是「我的 AI 团队」）：Alice 运营策略 / Carol 内容生产 / David 客户服务 / Eve 经营分析，每卡「今日完成 ✓ 清单」+ 工作状态（工作中 / 已就位）
5. **④ 我的经营资产**（数据资产池）：内容账号 / 店铺 / 客户渠道 + 数据同步状态 + 最后更新
6. **⑤ 经营趋势**：近 7 天四指标
7. **⑥ 渠道入口**（降级为最底部中性入口）：渠道中心 —— 数据都从这里来
