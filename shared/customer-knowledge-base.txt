## 一、昆仑镜是什么？

昆仑镜是一个在线的 AI 短剧和广告创作平台，直接在浏览器里使用。用户可以从一个灵感开始，在系统的帮助下完成剧本、角色设计、分镜、视频生成到最终成片的全过程。

**核心特点：** 用户自己的大模型 API Key 自己带（BYOK），平台不提供大模型能力。免费会员每天有 3 次使用官方 Key 的额度。

**访问地址：** https://aigc.fushtn.com

## 二、创作工作流（共8步，口语化版）

工作台里按顺序走这 8 步：

### 第1步：剧本分析 📝
**做什么：** 用户给出一个创意（一句话脑洞、小说片段、或者完整剧本稿），系统会自动分析，把故事拆解成场景、角色、台词、情绪这些基本元素。

**注意：**
- 分析完的结果用户可以看、可以改，不满意直接改
- 这是所有步骤的起点，没剧本啥都干不了
- **这一步用的是大语言模型（LLM），用户需要在"大模型设置"里配置 LLM 的 API Key**

### 第2步：角色设定 👤
**做什么：** 为剧中的每个角色设计外貌、性格、服装。系统会生成角色的四视图（大头照+正/侧/背面），保证角色在不同画面里形象一致。

**注意：**
- 角色可以穿多套不同的服装，随时换装
- **这一步用的是图片生成模型，用户需要配置图片（Image）的 API Key**
- 建议配置火山引擎 Seedream 模型

### 第3步：场景设定 🏙️
**做什么：** 设计每个场景发生在什么地方。咖啡馆、古堡、太空站都可以。场景风格统一，前后画面不跳戏。

**注意：**
- 跟角色设定一样，也需要图片生成 API Key
- 场景图在分镜阶段会用上

### 第4步：道具设定 🛡️（可选）
**做什么：** 如果故事里有特殊物品（魔法剑、药瓶、信物），在这里定义和生成图片。

**注意：**
- 这是可选步骤，跳过不影响成片
- 仍需要图片 API Key

### 第5步：分镜图 🖼️（可选）
**做什么：** 给每个镜头生成一张参考画面，作为视频生成的视觉基准。

**注意：**
- 可选步骤，跳过不影响视频生成
- 需要图片 API Key

### 第6步：视频生成 🎥
**做什么：** 系统根据剧本+角色+场景，自动为每个分镜头生成视频片段。可以一张一张生成，也可以批量生成。

**注意：**
- **这一步需要配置视频（Video）的 API Key**
- 推荐使用火山引擎 Seedance 系列模型
- 生成后可以预览效果

### 第7步：配音合成 🎙️（可选）
**做什么：** AI 给角色配上对白语音，可以选择不同的音色。

**注意：**
- 可选步骤，跳过也可以手动配音
- 需要配置 TTS（语音合成）的 API Key

### 第8步：音乐生成 🎵（可选）
**做什么：** AI 根据剧情自动生成合适的背景音乐。

**注意：**
- 可选步骤，也可以自己上传音乐文件
- 需要配置音乐生成的 API Key（支持 Suno、天工音乐、Mureka）

### 最后：合成输出 ✨
**做什么：** 把所有片段、配音、音乐合并成一部完整的视频。可以预览完整成片，满意了就下载保存。

**注意：**
- 这是最后一步，不需要额外 API Key

### 工作流提醒：
- 第1、2、3、6、合成步骤是必须的骨架步骤
- 第4、5、7、8步是可选的，不做不影响成片
- 步骤顺序不能乱：没剧本就出不了角色，没角色就生成不了视频
- 配音和音乐可以和视频生成同步做，互不耽误
- **这8步是官方的标准工作流，后台管理员也可以自定义流程，所以您看到的步骤不一定严格按照这个顺序**

## 三、大模型设置（如何配置 API Key）

### 从哪里进入
在工作室左侧栏最下方，有一个"大模型设置"按钮（齿轮图标），点进去就能看到设置弹窗。

### 需要配置哪些
弹窗里有几张卡片，每张对应一类能力：

| 卡片 | 能力 | 建议供应商 | 说明 |
|------|------|-----------|------|
| 🤖 语言模型（LLM） | 剧本分析、聊天 | DeepSeek / 火山引擎 / 硅基流动 | 必须配，否则无法做剧本分析 |
| 🖼️ 图片生成（Image） | 角色/场景/道具图 | 火山引擎 Seedream | 必须配，否则没法生成角色图和场景图 |
| 🎥 视频生成（Video） | 生成视频片段 | 火山引擎 Seedance | 必须配，否则不能生成视频 |
| 🎙️ 语音合成（TTS） | 角色配音 | 硅基流动 / 阿里云 | 可选，不做配音可以不配 |
| 🎵 音乐生成 | 背景音乐 | Suno / 天工音乐 | 可选，不配也能出片 |

### 设置步骤
1. 在卡片里选择供应商（比如火山引擎）
2. 选择模型（比如 doubao-seedream-5-0）
3. 粘贴从供应商获取的 API Key
4. 点击"保存全部配置"
5. 检查一下每个卡片右上角的开关是否打开（绿色才启用）

### 怎么获取 API Key
- **火山引擎**：在火山引擎控制台创建 API Key，需要充值才能使用（注意：余额不足会报 AccountOverdueError）
- **DeepSeek**：在 deepseek.com 注册，创建 API Key
- **硅基流动**：在 siliconflow.cn 注册，创建 API Key
- **阿里云通义**：在阿里云控制台开通通义千问服务，获取 API Key

### 常见设置问题
- **"请先在大模型设置中配置 API Key"** — 哪类能力报错，就去配哪张卡片
- **"无法读取配置"** — 检查网络，或重新进入大模型设置页面再保存一次
- **免费会员**每天有 3 次使用平台官方 API Key 的额度，用完之后就需要自己配置

## 四、会员套餐

昆仑镜有 4 个会员等级：

| 等级 | 价格 | 有效期 | 说明 |
|------|------|--------|------|
| 🆓 免费会员 | 0元 | 永久 | 每日 3 次免费生成，使用平台 Key |
| 🎬 新人体验卡 | 9.9元 | 10天试用 | 500MB 存储，适合先体验 |
| 🥇 黄金会员 | 199元/月 | 30天 | 2GB 存储，适合轻度创作（原价299） |
| 💎 钻石会员 | 299元/月 | 30天 | 5GB 存储，无限使用（原价499） |
| 👑 年卡会员 | 2999元/年 | 365天 | 10GB 存储，最划算（原价3999） |

**重要提示：** 
- VIP 会员（黄金/钻石/年卡）都是自己配置 API Key 使用的，平台不提供 Key

## 五、积分系统

### 什么是积分
积分是昆仑镜平台内的虚拟货币，可以在后台由管理员操作充值，或者通过推荐新用户获得。

### 积分有什么用
- **升级代理商**：积分可以用来购买代理等级（中级/高级/超级代理）
- 积分不能直接提现，但与钱包里的佣金是分开的

### 如何获取积分
- 后台管理员手动充值
- 推荐新用户注册
- 代理商获得佣金后，可以兑换成积分

## 六、代理商系统

### 什么是代理商
用户购买代理套餐后，可以获得某一片区的代理权，当该片区有新用户注册并开通 VIP，代理商可以获得佣金。

### 代理等级与价格

**AgentPlan 套餐（直接购买成为代理商）：**

| 等级 | 价格 | 有效期 | 佣金比例 | 说明 |
|------|------|--------|----------|------|
| 区县级代理商 | 29,800元 | 36个月 | 35% | 辖区内所有会员开通VIP可获得35%佣金 |
| 地市级代理商 | 49,800元 | 36个月 | 10%~45% | 辖区内有下级区县代理时获10%，无下级时获45% |

**积分兑换等级：**

| 等级 | 所需积分 | 折扣 |
|------|---------|------|
| 中级代理 | 290,000 积分 | 85折 |
| 高级代理 | 590,000 积分 | 8折 |
| 超级代理 | 990,000 积分 | 75折 |

### 如何申请成为代理商
1. 登录后访问 `/user/agent` 页面
2. 选择"申请代理"
3. 选择代理等级和区域（省/市/区县）
4. 支付代理套餐费用或使用积分兑换
5. 平台审核通过后生效

### 佣金怎么结算
- 代理商根据辖区内的 VIP 会员消费获得比例佣金
- 佣金记入钱包余额
- 钱包余额满 100 元可申请提现
- 特殊品类（如视频生成）佣金比例减半

### 代理商权益
- 区县级：辖区会员 VIP 开通获得 35% 佣金
- 地市级：辖区无下级代理时获 45%，有下级代理时获 10%
- 代理商之间可以推荐发展下级代理

## 七、常见问题

### Q：生成图片/视频失败
**可能的原因：**
1. **API Key 欠费或无效** — 检查火山引擎/DeepSeek 等平台的余额
2. **API Key 未配置** — 去大模型设置看对应的卡片是否配置了
3. **免费会员额度用完** — 升级 VIP 或配置自己的 API Key
4. **供应商服务异常** — 稍后再试

### Q：API Key 配置后还是报错
- 检查 Key 前后有没有多出空格
- 确认选择了正确的供应商
- 确认供应商模型名称是否正确
- 火山引擎注意余额充足（AccountOverdueError = 欠费）

### Q：角色四视图生成不完整
- 系统会自动尝试多次生成，某一张失败不影响其他视图
- 最终会使用已生成成功的图片合成

### Q：免费会员每天 3 次额度怎么算
- 每次调用 AI 生成（剧本分析、角色图、视频等）算一次
- 每天 0 点重置
- 可以升级 VIP 或配置自己的 API Key 来解除限制

### Q：工作台步骤显示不对/卡住了
- 刷新页面试试
- 检查浏览器控制台是否有报错
- 后台管理员可以自定义工作流步骤

### Q：视频生成了但画面不对/质量差
- 检查角色的四视图是否清晰完整
- 检查场景描述是否详细
- 视频模型本身的质量也受用户配置的模型影响，建议使用最新的 Seedance 模型

## 九、超出能力范围的转人工规则

智能客服小麒如果遇到自己搞不定的问题，要引导用户加微信找人工。以下情况必须转人工：

### 必须转人工的场景
- **代理合作** — 用户询问如何成为区域代理、代理价格谈判、代理合同等商务合作
- **投资合作** — 投资人咨询、融资、战略合作等
- **系统故障** — 平台大面积故障、数据丢失、严重报错等非正常情况
- **大额定制** — 企业级定制开发、品牌合作等
- **其他商务合作** — 非产品使用类的深度商业问题

### 转人工话术模板
> "哎呀，这个问题有点深，小麒搞不定呢～您加我们主管微信吧：**qdkj-999**，添加时备注'昆仑镜用户'，他会帮您处理的！"

### 回答规则
- 不能装作自己能回答这些问题，要诚实说"超出能力范围"
- 必须提供微信号 **qdkj-999**
- 必须提醒用户备注"昆仑镜用户"
- 说完转人工后不要再追问其他问题

## 十、技术说明（管理员用）

### 系统架构
- 前端：Nuxt 3 SPA
- 后端：Fastify + Prisma
- 数据库：PostgreSQL 16
- 队列：BullMQ (Redis)

### 用户隔离策略
- **BYOK 100% 隔离**：每个用户的 API Key 只从自己的 UserModelConfigV2 表读取
- 用户没有配置 Key 时，直接提示"请配置 API Key"，不会使用其他人的 Key 或全局 Key
- free tier 用户每天有 3 次使用平台 Key 的额度
