## 一、🔴 P0 — 立即可修复安全问题

### 1.1 admin-storage-config.ts 完全无认证
- **文件**: `backend/src/routes/admin-storage-config.ts`
- **描述**: GET/POST/DELETE /api/admin/storage-config 共 5 个端点无任何认证中间件，COS 存储配置（含加密密钥）暴露
- **风险**: 任何知道此接口的人可直接读取/修改存储密钥
- **修复**: 添加 `preHandler: [requireAdmin]`

### 1.2 project.service.ts findById 越权
- **文件**: `backend/src/services/project.service.ts` 中 `findById(id)`
- **描述**: 只校验了 JWT 有效，未校验 `project.userId === currentUserId`
- **风险**: 用户 A 知道 B 的项目 ID 即可读取其 storyboard 和 videoTask
- **修复**: 添加 userId 过滤

### 1.3 支付通知竞争条件（双倍扣款风险）
- **文件**: `routes/payment.ts:430-510` — `handleVipRechargeOrder`
- **描述**: 支付宝/微信异步通知可重复回调，`if (order.status === 'paid') return` 不在事务内
- **风险**: 并发回调导致积分/会员资格被双重激活
- **修复**: 用原子性 update 做状态预占位

### 1.4 process.env API Key 污染
- **文件**: `model-adapters/registry.ts:122-130`
- **描述**: 执行前将用户 API Key 写入 `process.env`，finally 中 `delete`，存在并发竞争
- **风险**: 用户 A 的请求可能使用用户 B 的 API Key
- **修复**: 废弃 process.env 写入模式，provider 显式接收 apiKey 参数

### 1.5 积分扣减非原子性（透支漏洞）
- **文件**: `routes/user-center.ts:49-62`
- **描述**: 先读余额再扣减，两个操作无事务
- **风险**: 并发请求可超额消耗积分
- **修复**: 用 `update({ where: { userId, credits: { gte: amount } } })` 做原子扣减

### 1.6 内存缓存无限增长（OOM 风险）
- **文件**: 
  - `routes/auth.ts:30` — `loginAttempts` Map
  - `services/gateway-guard.ts:30` — `userCallCounts` + `projectConcurrency` Map
- **描述**: 三个缓存无容量上限和自动清理机制
- **风险**: 长期运行后内存耗尽
- **修复**: 实现定时清理或迁移到 Redis

## 二、🟠 P1 — 高优先级

### 2.1 同步 I/O 阻塞事件循环
- **文件**: 多处 — `volcengine-video.adapter.ts`、`siliconflow-tts.adapter.ts`、`images.ts` 等
- **描述**: API 路径中使用 `writeFileSync`、`readFileSync`、`readdirSync` 等同步操作
- **风险**: 高并发下延迟雪崩
- **修复**: 替换为 `fs.promises` API

### 2.2 AbortSignal.timeout 未清理（内存泄漏）
- **文件**: `volcengine-video.adapter.ts`、`openai-compat.adapter.ts`、`dalle-image.adapter.ts` 等
- **描述**: 所有 adapter 使用 `AbortSignal.timeout(120000)` 但请求完成后未清理
- **风险**: 长期运行后内存线性增长
- **修复**: 使用 `AbortController` + `clearTimeout()`

### 2.3 轮询 300 次无超时上限
- **文件**: `volcengine-video.adapter.ts:216`
- **描述**: `for (let i = 0; i < 300; i++)` 轮询 5 分钟无硬超时
- **风险**: 连接池耗尽
- **修复**: 添加 `AbortSignal.timeout(300000)`

## 三、🟡 P2 — 中优先级

### 3.1 火山引擎 API endpoint 硬编码
- **涉及 adapter**: siliconflow-image、dalle-image、aliyun-tts、siliconflow-tts、qwen-image
- **问题**: BASE_URL 硬编码，未使用 `runtime.baseURL` 或 `input.baseUrl`
- **修复**: 统一使用 `runtime.baseURL || input.baseUrl || DEFAULT_BASE_URL`

### 3.8 静默 `catch {}` — 至少 17 处

### 3.11 PM2 实例重启 180-190 次

## 五、🎨 前端专项
