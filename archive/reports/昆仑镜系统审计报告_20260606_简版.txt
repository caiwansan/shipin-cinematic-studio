二、P0 - 必须立即修复
──────────────────────────────────────

1. .env 文件包含所有生产密钥明文
   阿里云/火山引擎/DeepSeek/MinIO/数据库密码全部明文写入 .env 和 .env.bak

2. ApiKey 表明文存储密钥
   admin-api-keys.ts 以明文存用户 API Key，而另一套路由 admin-models-v2.ts
   用 AES 加密，存在两套重叠逻辑（一套明文一套加密）

3. voice.ts 未解密 API Key（重要！）
   用户设置的 API Key 经过 AES-256-GCM 加密后存入数据库，但 voice.ts 读取后
   直接当作真实 API Key 传给火山引擎 TTS → 所有 TTS/Image 调用认证失败

4. 数据库连接池不足
   6 个 PM2 实例 × 8 个 PrismaClient = 至少 48 连接需求，
   但 PostgreSQL 限定了全局 connection_limit=5，并发 >5 就 503

5. 管理后台安全缺失
   - CSP/X-Frame-Options/HSTS 等安全头部全部缺失
   - 所有云密钥在前端明文展示且可直接修改
   - admin 路由守卫被跳过

6. Agent 三套并行代码
   aigc-spec-agent.ts(v1) + aigc-spec-agent-v2.ts(v2) + aigc-orchestrator.ts(v3)
   修改 prompt 需同步 3 处

三、P1 - 高优先级
──────────────────────────────────────
7. CORS origin:true → 所有域名可跨域访问
8. OAuth 回调 HTML 拼接 token → XSS 注入风险
9. localStorage+Cookie 双存 token → XSS 可窃取
10. v-html 渲染社区帖子，sanitizer 可绕过
11. JWT Secret 默认值公开 → 可伪造 token
12. userId:'system' 硬编码 13 处 → 绕过鉴权
13. 广告视频生成强制 volcengine → 无视用户配置
14. Worker concurrency=10 → 打爆数据库连接
15. 大文件 base64 → 浏览器 OOM 风险
16. 任务重复执行 → 缺少 upsert 幂等性
17. 域名 aigc.fushtn.com 硬编码 5 处
18. 默认 provider 全 volcengine → 用户切换无效
